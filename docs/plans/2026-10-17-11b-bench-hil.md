# Plan 11b: the bench HIL runs and the acceptance gates

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native, chosen) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every bench suite of `stm32/firmware/test/bench` passes on the board as it now stands (routed LAN, DHCP), the spec §12.2/§12.3 gates that this bench can measure are measured, and a report records what passed, what was fixed and what still needs equipment the bench lacks.

**Architecture:** one module, `bench_env.py`, owns the bench's addresses (the board, the Windows host) and every suite takes them from it; then the suites run one at a time on the board (one client of COM4 and of the board at a time), each failure is debugged to its cause and fixed with a test, and the results go into `stm32/docs/reports/2026-10-17-11b-bench.md`. No new firmware feature.

**Tech Stack:** Python 3 bench scripts (WSL, Windows Python for the peers through `win_peer.py`), the board's web API and UART7 console (`board.py`, COM4), mosquitto in WSL, OpenOCD/STM32CubeProgrammer over SWD.

**Spec:** `stm32/docs/specs/2026-10-14-stm32-firmware-design.md` §12.2 (bench HIL), §12.3 (memory scenarios), §6.1 (`iwdgMaxGapMs` < 400 ms, `wdiMaxGapMs` < 600 ms), §11.4 (supervisor, `hbMissing` 0); roadmap row 11 (`2026-10-14-00-roadmap.md`).

## Global Constraints

- The bench (the user, 2026-10-17): the board on a routed LAN, DHCP, now **192.168.1.9**; the Windows host on that LAN by **Wi-Fi 192.168.1.3** (its Ethernet 192.168.0.10 no longer reaches the board); **DO1 wired to DI1** (DO2 to nothing); the RS485 loop UART1-UART2; R103 not fitted.
- WSL is behind NAT: the board can reach Windows only, so every peer the board dials runs on Windows (`win_peer.py`), and the Windows firewall must let them in on the Wi-Fi network.
- One client of the board at a time: never two suites, or a suite and a manual command, on COM4 or the web at once (Plan 11a lesson).
- Do not run what re-attaches the LTE modem (the SIM was locked by the Plan 10b bench): `lte_check.py`, `defaults_check.py`, a factory reset (it sets `network.priority` 1), the Reload 10-15 s case, the bench console's `Z`/`WIPE`, and **`store_check.py` case 5** (the app's SPI4 init forced to fail: the store does not mount, the defaults run, priority 1; Codex). `network.priority` stays 0: every `network` a suite writes is built from the **whole saved document** with `priority` 0 kept (Codex: a partial document takes the default 1). (`ota_check`'s SPI4 failure is the bootloader's: the app's store mounts; it stays in.)
- Configs apply at boot; Restart Hold and Timer flip as PR #29 (the bench follows them).
- Keep it simple: fix a bench script when it assumes the old bench; fix the firmware only for a real defect, each with a host test first (TDD) and its own commit.
- Run only the affected tests after an edit.

## Review Focus

1. A DHCP lease that changes between runs or after a suite moves the board: every suite reaches the board at its current address or stops with a clear message; never a guessed one (Task 1: no fallback address; `bench_env.set_board()` after a move; tests for a failed search and a changed lease).
2. Peers blocked by the Windows firewall on a Public network: a suite must say so plainly, not report a firmware failure (Task 1: `bench_env.check_peer()` before the suites that need peers).
3. TLS certificates made for the old host address: the bench PKI must be remade when the Windows address changes (Task 1: `tls_check.make_pki` keyed on the address).
4. A suite that changes the board's network (net_check, disc_check) must leave it reachable at the address it found (Task 2: both restore the saved `network` config).
5. Suites written before PR #29 that expect a flash-restored DO or a Timer flip that waits for a command (io_check, review_check): they must test today's behaviour (Task 3).

```python
"""The bench's addresses (Plan 11b): the board and the Windows host on the board's LAN, in one place.

    SBIOT_GW   the board (default: found by a FinderTool search from SBIOT_WIN, by its SN)
    SBIOT_WIN  Windows on the board's LAN (default 192.168.1.3, the Wi-Fi of the bench PC since 2026-10-17)
    SBIOT_SN   the bench board's SN (default SB2610000001)

WSL is behind NAT: the board reaches Windows only, so the peers it dials run there (win_peer.py)."""
import ipaddress
import json
import os
import random
import subprocess
import sys

WIN = os.environ.get('SBIOT_WIN', '192.168.1.3')
SN = os.environ.get('SBIOT_SN', 'SB2610000001')
WIN_PY = '/mnt/c/Python311/python.exe'


def pick(lines, req_id, sn):
    """The `found` reply to our search `req_id` from the board `sn`, as a dict; None for anything else. Its address
    must be a usable unicast IPv4 (Codex: no broadcast, multicast, 0.0.0.0, leading zeros, odd digits)."""
    for line in lines:
        try:
            r = json.loads(line)
            ip = ipaddress.IPv4Address(r['eth']['ip'])
        except (ValueError, KeyError, TypeError, ipaddress.AddressValueError):
            continue
        try:
            net = ipaddress.IPv4Network('%s/%s' % (ip, r['eth'].get('netmask', '255.255.255.255')), strict=False)
        except ValueError:
            continue
        if (r.get('sbiot') == 'disc' and r.get('v') == 1 and r.get('op') == 'found' and r.get('id') == req_id
                and r.get('sn') == sn and not (ip.is_multicast or ip.is_unspecified or ip.is_loopback or ip.is_reserved)
                and (net.prefixlen >= 31 or ip not in (net.network_address, net.broadcast_address))):
            return r
    return None


def find_board(win, sn):
    """The board's running Ethernet address by FinderTool's search from Windows (spec 2026-10-17-lan-discovery-design.md)."""
    req_id = '%08x' % random.getrandbits(32)
    pkt = json.dumps({'sbiot': 'disc', 'v': 1, 'op': 'search', 'id': req_id})
    code = ('import socket,time\n'
            's=socket.socket(2,2);s.setsockopt(socket.SOL_SOCKET,socket.SO_BROADCAST,1);s.bind((%r,0));s.settimeout(0.2)\n'
            's.sendto(%r.encode(),("255.255.255.255",48600));t=time.time()\n'
            'while time.time()-t<2:\n'
            '    try: print(s.recvfrom(2048)[0].decode())\n'
            '    except socket.timeout: pass\n') % (win, pkt)
    try:
        out = subprocess.run([WIN_PY, '-c', code], cwd='/mnt/c', capture_output=True, text=True, timeout=20).stdout
    except (OSError, subprocess.TimeoutExpired):
        return None
    return pick(out.splitlines(), req_id, sn)  # the whole reply: eth.ip, boot, …


def resolve_gw():
    gw = os.environ.get('SBIOT_GW') or (find_board(WIN, SN) or {}).get('eth', {}).get('ip')
    if not gw:
        raise RuntimeError('the board %s did not answer a search from %s: set SBIOT_GW, or check the LAN' % (SN, WIN))
    return gw


GW = resolve_gw()


def set_board(ip):
    """The board moved (net_check, disc_check, a new lease): every client that copied the address follows."""
    global GW
    GW = ip
    if 'web_check' in sys.modules:
        sys.modules['web_check'].HOST = ip
    if 'bridge_check' in sys.modules:
        sys.modules['bridge_check'].GW = ip


def gates(label, path=None):
    """The §6.1/§11.4/§12.2 counters of this boot, read now (they reset at every restart, so a suite calls this
    right after its load and before it restarts the board; Codex): appended as one JSON line to `path`. The boot
    number comes from the FinderTool reply (`found.boot`; the status has none). Missing counters are an error."""
    import web_check as w
    found = find_board(WIN, SN)
    _, st = w.get_json('/api/status')
    sy, mem = (st or {}).get('system', {}), (st or {}).get('mem', {})
    row = {'label': label, 'boot': (found or {}).get('boot'), 'uptime': sy.get('uptime'),
           'iwdgMaxGapMs': sy.get('iwdgMaxGapMs'), 'wdiMaxGapMs': sy.get('wdiMaxGapMs'), 'hbMissing': sy.get('hbMissing'),
           'heapLargest': sy.get('heapLargest'), 'heap': mem.get('heap'), 'stackMin': mem.get('stackMin'),
           'uart': mem.get('uart'),
           'poolsFull': [p['name'] for p in mem.get('pools', []) if p.get('used') == p.get('size')]}
    missing = [k for k in ('boot', 'uptime', 'iwdgMaxGapMs', 'wdiMaxGapMs', 'hbMissing', 'heap', 'stackMin', 'uart')
               if row[k] is None]
    if missing:
        raise RuntimeError('gates %s: no %s' % (label, ', '.join(missing)))
    with open(path or os.environ.get('SBIOT_GATES', '/tmp/sbiot_gates.jsonl'), 'a') as f:
        f.write(json.dumps(row) + '\n')
    return row


def same_boot(before, after):
    """A workload qualifies only if the board did not restart under it (Codex): the two gate rows' boot numbers."""
    return before['boot'] == after['boot']


def check_peer():
    """True when the Windows firewall lets the peers in: a rule allowing C:\\Python311\\python.exe inbound whose
    profiles include the board's LAN's (read-only; the agent never changes the firewall). A connection from WSL
    cannot tell, since it reaches Windows through the WSL adapter, not the LAN's."""
    ps = ("$cat = (Get-NetConnectionProfile | Where-Object { (Get-NetIPAddress -InterfaceIndex $_.InterfaceIndex "
          "-AddressFamily IPv4 -ErrorAction SilentlyContinue).IPAddress -eq '%s' }).NetworkCategory; "
          "$ok = Get-NetFirewallApplicationFilter -Program 'C:\\Python311\\python.exe' -ErrorAction SilentlyContinue | "
          "Get-NetFirewallRule | Where-Object { $_.Enabled -eq 'True' -and $_.Direction -eq 'Inbound' -and "
          "$_.Action -eq 'Allow' -and ($_.Profile -eq 'Any' -or $_.Profile -match $cat) }; "
          "if ($ok) { 'ok' } else { 'blocked ' + $cat }") % WIN
    out = subprocess.run(['powershell.exe', '-NoProfile', '-Command', ps], cwd='/mnt/c', capture_output=True,
                         text=True, timeout=60).stdout.strip()
    return out == 'ok', out or 'PowerShell gave nothing'  # a hint, not proof (Codex): the peers' own checks decide
```

- [ ] **Step 2: Scenario B (many TLS), as a sequence with evidence** (Codex):
  1. **Everything configured first, one restart** (Codex: the outbox is RAM, a restart empties it): MQTT over TLS with `bufferOffline` 1 at a Windows port **nobody listens on yet**, UART1 a TLS TCP client and UART2 an HTTPS client at two more Windows ports, likewise not listening yet.
  2. **Outbox full, offline:** serial data sent into UART1's MQTT uplink path (the RS485 loop, `send_serial`) until the board's log shows the firmware's existing "outbox full" line (no status field has it: `api.c` reports only `enabled`/`state`).
  3. **One process, one clock** (Codex): a new `win_peer.py` mode `tlsset` runs the three listeners in threads of one process — a `tlsserver` for MQTT that **completes the TLS handshake and never answers** (no CONNACK: the handshake's memory is spent while the outbox stays full), a `tlsserver` for UART1 and an `https` for UART2 — each logging `accept` and `hs` events with the process's common `t` and its port. It starts on the three ports **without restarting the gateway**; the board's clients dial as their retries come. Overlap is shown when the three [accept, hs] intervals intersect.
  4. **A slow reader:** a Windows peer GETs the UI at 1 KB/s for the whole window.
  5. **FlashDB GC:** config saves in a row (as `store_check`'s stress) during the window until the store reports a GC (the console's or the log's GC line; if the firmware logs none, the case says "GC not evidenced").
