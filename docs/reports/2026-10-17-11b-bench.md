# Plan 11b: bench HIL run (2026-10-17)

Board SBIOT-H750, SN SB2610000001, MAC 02:95:b8:e9:a7:9f, app 0.7.0 (main after PR #31, plus this branch's fixes), bootloader of PR #29. R103 not fitted.

Bench:
- Ethernet: a direct cable to the PC (Windows Ethernet 192.168.0.10; the board static 192.168.0.7/24). Disc and net ran first on the routed LAN (DHCP 192.168.1.9), before the bench was re-cabled.
- Wiring: DO1 wired to DI1; UART1 and UART2 tied by the RS485 loop.
- Console and SWD: the UART7 console through the ST-Link VCP (COM4); SWD through STM32CubeProgrammer and OpenOCD.
- Peers: on Windows Python (`win_peer.py`); mosquitto in WSL.
- SIM: the SIM is locked (Plan 10b), so `network.priority` stays 0 and nothing re-attaches the modem.

Logs: one file per suite, the board's `/api/log` after each suite, and `gates.jsonl` (24 rows), all in the plan's workspace. Each workload's gate row is read before and after it, on the same boot (`bench_env.qualify`).

### Needs equipment (or a SIM, or the user)

- **OTA cut by power 20 times:** a USB relay on the board's supply. Only NRST resets mid-install were run (`ota_check`, 5 cut, then 1 completed).
- **ADC acceptance (§6.6):** a 4–20 mA source, a 50/60 Hz injector, two independently controlled channels (crosstalk) and a step-capable source (latency): `io_check adcpoint adccal adc`. Only the baseline ran (`adcbase`).
- **DE, t1.5/t3.5, WDI and OE on the pins during a reset:** a logic analyser or a scope, and a timed RS485 generator.
- **Two buses at once** (Edge on UART2 while the bridge runs on UART1): a second RS485 device, since the loop ties UART1 to UART2.
- **PPP + CMUX, priority switching, DLC recovery, the LAN flood with PPP loading, the first format:** a working SIM (`lte_check`, `defaults_check`, `store_check` case 5).
- **The cold boot** (`boot_check --cold`): the user cycles the power.
