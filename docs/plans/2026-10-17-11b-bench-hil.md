# Plan 11b: the bench HIL runs and the acceptance gates

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native, chosen) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every bench suite of `stm32/firmware/test/bench` passes on the board as it now stands (routed LAN, DHCP), the spec §12.2/§12.3 gates that this bench can measure are measured, and a report records what passed, what was fixed and what still needs equipment the bench lacks.

**Architecture:** one module, `bench_env.py`, owns the bench's addresses (the board, the Windows host) and every suite takes them from it; then the suites run one at a time on the board (one client of COM4 and of the board at a time), each failure is debugged to its cause and fixed with a test, and the results go into `stm32/docs/reports/2026-10-17-11b-bench.md`. No new firmware feature.

**Tech Stack:** Python 3 bench scripts (WSL, Windows Python for the peers through `win_peer.py`), the board's web API and UART7 console (`board.py`, COM4), mosquitto in WSL, OpenOCD/STM32CubeProgrammer over SWD.

**Spec:** `stm32/docs/specs/2026-10-14-stm32-firmware-design.md` §12.2 (bench HIL), §12.3 (memory scenarios), §6.1 (`iwdgMaxGapMs` < 400 ms, `wdiMaxGapMs` < 600 ms), §11.4 (supervisor, `hbMissing` 0); roadmap row 11 (`2026-10-14-00-roadmap.md`).

## Global Constraints

- The bench (the user, 2026-10-17): the board on a routed LAN, DHCP, now **192.168.1.9**; the Windows host on that LAN by **Wi-Fi 192.168.1.3** (its Ethernet 192.168.0.10 no longer reaches the board); **DO1 wired to DI1** (DO2 to nothing); the RS485 loop UART1-UART2; R103 not fitted.
- WSL is behind NAT: the board can reach Windows only, so every peer the board dials runs on Windows (`win_peer.py`), and the Windows firewall must let them in on the Wi-Fi network.
- One client of the board at a time: never two suites, or a suite and a manual command, on COM4 or the web at once (Plan 11a lesson).
- Do not run what re-attaches the LTE modem (the SIM was locked by the Plan 10b bench): `lte_check.py`, `defaults_check.py`, a factory reset (it sets `network.priority` 1), the Reload 10-15 s case. `network.priority` stays 0.
- Configs apply at boot; Restart Hold and Timer flip as PR #29 (the bench follows them).
- Keep it simple: fix a bench script when it assumes the old bench; fix the firmware only for a real defect, each with a host test first (TDD) and its own commit.
- Run only the affected tests after an edit.

## Review Focus

1. A DHCP lease that changes between runs: every suite must reach the board at its current address, not a stale one (Task 1: `bench_env.GW` resolved by a FinderTool search when `SBIOT_GW` is not set).
2. Peers blocked by the Windows firewall on a Public network: a suite must say so plainly, not report a firmware failure (Task 1: `bench_env.check_peer()` before the suites that need peers).
3. TLS certificates made for the old host address: the bench PKI must be remade when the Windows address changes (Task 1: `tls_check.make_pki` keyed on the address).
4. A suite that changes the board's network (net_check, disc_check) must leave it reachable at the address it found (Task 2: both restore the saved `network` config).
5. Suites written before PR #29 that expect a flash-restored DO or a Timer flip that waits for a command (io_check, review_check): they must test today's behaviour (Task 3).

```python
"""The bench's addresses (Plan 11b): the board and the Windows host on the board's LAN, in one place.

    SBIOT_GW   the board (default: found by a FinderTool search from SBIOT_WIN, by its SN)
    SBIOT_WIN  Windows on the board's LAN (default 192.168.1.3, the Wi-Fi of the bench PC since 2026-10-17)
    SBIOT_SN   the bench board's SN (default SB2610000001)

WSL is behind NAT: the board reaches Windows only, so the peers it dials run there (win_peer.py)."""
import json
import os
import random
import subprocess

WIN = os.environ.get('SBIOT_WIN', '192.168.1.3')
SN = os.environ.get('SBIOT_SN', 'SB2610000001')
WIN_PY = '/mnt/c/Python311/python.exe'


def find_board(win, sn):
    """The board's running Ethernet address from FinderTool's search (spec 2026-10-17-lan-discovery-design.md), or None."""
    pkt = json.dumps({'sbiot': 'disc', 'v': 1, 'op': 'search', 'id': '%08x' % random.getrandbits(32)})
    code = ('import socket,json,time\n'
            's=socket.socket(2,2);s.setsockopt(socket.SOL_SOCKET,socket.SO_BROADCAST,1);s.bind((%r,0));s.settimeout(0.2)\n'
            's.sendto(%r.encode(),("255.255.255.255",48600));t=time.time()\n'
            'while time.time()-t<2:\n'
            '    try: print(s.recvfrom(2048)[0].decode())\n'
            '    except socket.timeout: pass\n') % (win, pkt)
    try:
        out = subprocess.run([WIN_PY, '-c', code], cwd='/mnt/c', capture_output=True, text=True, timeout=20).stdout
    except (OSError, subprocess.TimeoutExpired):
        return None
    for line in out.splitlines():
        try:
            r = json.loads(line)
        except ValueError:
            continue
        if r.get('op') == 'found' and r.get('sn') == sn:
            return r['eth']['ip']
    return None


def resolve_gw():
    return os.environ.get('SBIOT_GW') or find_board(WIN, SN) or '192.168.1.9'


GW = resolve_gw()


def check_peer():
    """True when the Windows firewall lets the peers in: a rule allowing C:\\Python311\\python.exe inbound whose
    profiles include the board's LAN's (read-only; the agent never changes the firewall). A connection from WSL
    cannot tell, since it reaches Windows through the WSL adapter, not the LAN's."""
    ps = ("$cat = (Get-NetConnectionProfile | Where-Object { (Get-NetIPAddress -InterfaceIndex $_.InterfaceIndex "
          "-AddressFamily IPv4 -ErrorAction SilentlyContinue).IPAddress -eq '%s' }).NetworkCategory; "
          "$ok = Get-NetFirewallApplicationFilter -Program 'C:\\Python311\\python.exe' -ErrorAction SilentlyContinue | "
          "Get-NetFirewallRule | Where-Object { $_.Enabled -eq 'True' -and $_.Direction -eq 'Inbound' -and "
          "$_.Action -eq 'Allow' -and ($_.Profile -eq 'Any' -or $_.Profile -match $cat) }; "
          "if ($ok) { 'ok' } else { 'blocked ' + $cat }") % WIN
    out = subprocess.run(['powershell.exe', '-NoProfile', '-Command', ps], cwd='/mnt/c', capture_output=True,
                         text=True, timeout=60).stdout.strip()
    return out == 'ok'
```

Then: `web_check.py` `HOST = bench_env.GW`; `bridge_check.py` `GW, WIN = bench_env.GW, bench_env.WIN`, `WIN_PY = bench_env.WIN_PY`; `serial_check.py` flood target `bench_env.GW`; `tls_check.make_pki` remakes the PKI when `PKI/ip.txt` differs from `WIN` (writes it after); texts in `mqtt_check.py`, `io_check.py`, `serial_check.py` name "the board" instead of 192.168.0.7. The `allowedClients='192.168.0.99'` cases stay (an address that is not the peer, on any LAN).
