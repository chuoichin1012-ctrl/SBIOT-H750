# Plan 04a: OTA image format and the bootloader's install logic, host first

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The whole OTA decision logic of spec §11.2 and the app side of §11.3 exist as plain C over a NOR flash interface, proven on the host against simulated flash that loses power at every erase and program.

**Architecture:**
- **`components/ota`**, shared by the bootloader and the app:
  - `sha256`, and `ota_image` (header format, `img_check`);
  - `bootrec` (A/B state record), `handoff` (backup-SRAM block);
  - `ota_app` (staging writer, confirm, rollback).
- **`boot/install.c`:** the decision table rows 1–10, the state machine, the RAM-tracked path and the rescue retry.
- **`tools/mkimage.py`:** writes the image header after the build.
- **`test/host/nor_sim`:** a NOR flash with partial writes and erases on a power cut, deadlines, and failing regions.
- **`test_install`:** one case per row and per §12.1 item, plus two matrices that cut power at every operation of an install and of a rollback.
- **`mutants_ota.py`:** proves the tests catch 20 deliberate faults.
- **Board side:** nothing here runs on the board. Plan 04b wires the logic into the bootloader with the SPI4 driver and QSPI programming.

**Tech Stack:** C11, gcc with ASan/UBSan, GNU make, Python 3 (hashlib, zlib).

**Spec:** `stm32/docs/specs/2026-10-14-stm32-firmware-design.md` §5.1, §5.2, §11.1, §11.2, §11.3, §12.1 (bootloader row). **Roadmap:** row 04, split here into 04a (host) and 04b (board).

## Design decisions to review

| # | Decision | Why |
|---|---|---|
| D1 | `Vq`, `Vb` and `Vs` are computed **on demand and cached** until that slot is written, instead of all three up front. A normal boot (CONFIRMED, QSPI good) hashes only QSPI | The table is a pure function of the flash contents, so evaluation order does not change any decision. It saves about 0.4 s of SPI4 reads per boot |
| D2 | A checkpoint whose read-back differs from the source, or a read that fails with an error other than a timeout, ends the boot with `INSTALL_REBOOT`. The attempt is already counted, so rows 7–9 end a persistent fault. **Any timeout**, whether of an erase, a program, a source read or a read-back, is row 2 (`INSTALL_WATCHDOG`), on the checkpoint path and on the RAM path alike | §11.2 asks for read-back but names no reaction. Treating it like a cut keeps a single counter ("không phân biệt mất nguồn với lỗi flash") |
| D3 | VERIFY and the post-RESTORE check are `img_check` of QSPI **plus** equality of its header core with the copy kept in the record. The BACKUP check is `img_check` of the backup plus equality with the running image's header | A valid image that is not the intended one counts as a failure |
| D4 | The rescue retry resets `ram_fail`, then picks its source:<br>• from backup it sets `RESTORE(0)`, so success ends in `CONFIRMED`;<br>• from staging it sets `WRITE(0)` with fresh counters, so success goes through VERIFY to `TRIAL(0)`, as §11.2 requires;<br>• with no source but a valid QSPI, it sets `CONFIRMED` and runs QSPI (row 1 halts only when nothing is valid);<br>• when it cannot read or write its record, rows 3–6 apply as anywhere else: a valid QSPI runs degraded and is never erased, `rec_fail` is counted, and only then comes the RAM path | This is the spec's wording, expressed with the existing states; Codex r1 found the first version skipping rows 1 and 3–4 here |
| D5 | The RAM path's own "`ram_fail` > 3" gives `INSTALL_RESCUE_RETRY` (step 2 of the RAM path), separate from row 9 | It is step 2 of the RAM path, not a table row |
| D6 | The record's `degraded` byte says that **the previous boot** ran degraded. It is set on the next record that can be written. The current boot's flag is in the handoff block for the app | §11.2 "lần boot trước không ghi được bản ghi trạng thái" |
| D7 | In TRIAL, a record write that fails after the trial increment is row 4: the app runs degraded and cannot confirm. Whether the trial is counted depends on what reached the flash. If only the read-back failed, the new record is valid and the next boot sees the trial counted (tested) | §11.2 row 4, last sentence |
| D8 | `ota_stage_begin` refuses (409) unless the record is CONFIRMED (or absent) **and** the handoff block is not degraded. So an upload is refused not only in TRIAL but during any unfinished install. A record that **cannot be read** refuses too, with 500 | §11.3 forbids OTA during TRIAL; any other state means an install is under way; an unknown state is never assumed to be CONFIRMED |
| D10 | `bootrec_read` has three outcomes: valid, none valid, read error. A read error is never "no record":<br>• the bootloader treats it as rows 3–6;<br>• `bootrec_write` writes nothing, so the newest copy is never erased;<br>• the app refuses OTA, confirm and rollback | Codex r1: an unreadable newest copy must not be erased or skipped |
| D9 | PENDING is written only by `ota_stage_finish`, after the streamed SHA **and** a full `img_check` read back from staging | §11.3 "kết thúc mà khớp thì ghi PENDING". The read-back also catches programming errors on SPI4 |

## Global Constraints

- **Image header** (offsets in bytes, little endian):
  - 0: magic `SBIO`;
  - 4: hardware id `SBIOT-H750`, NUL-padded to 16 bytes;
  - 20: version, 3 × u16, then u16 0;
  - 28: body size, u32;
  - 32: SHA-256 of the body;
  - 64: CRC-32 of bytes 0–63;
  - 68–1023: 0xFF.
- **Image size and vectors:**
  - the body starts at 0x400 with the vector table, and its size is 8 bytes to 1 472 KB − 1 KB;
  - MSP inside (0x20000000, 0x20020000] or (0x24000000, 0x24080000], 8-byte aligned;
  - the reset vector has the Thumb bit and lies in [0x90000400, 0x90000400 + size).
- **Flash map:**
  - QSPI: slot at 0.
  - SPI4: records A 0x100000 and B 0x101000; staging 0x110000; backup 0x280000.
  - The slot is 0x170000 bytes. A checkpoint is 64 KB, an erase 4 KB, a program one 256-byte page (spec §5.2).
- **Record:** body in page 0 (magic `BREC`, seq, state, offset, trial, attempts, verify_fail, degraded, reason, two 68-byte header cores). Page 1 holds the CRC-32 of the body and the magic, programmed last. The newest is `(int32_t)(a − b) > 0`.
- **Handoff block:** 64 bytes (magic `HOFF`, rec_fail, ram_fail, degraded, reason, CRC-32). Wrong magic or CRC means all zero.
- **Limits:** trial boots ≤ 3. `attempts > 3` and `verify_fail ≥ 2` exhaust a phase. `rec_fail ≥ 3` leads to the RAM path, and `ram_fail > 3` to a rescue retry.
- **Code style:**
  - our C is `-std=c11` with the existing host flags (`-Wall -Wextra -Wno-unused-parameter -Werror -O1 -g -fsanitize=address,undefined -fno-sanitize-recover=all`), 4-space indent, `//` comments;
  - the code in `components/ota` and `boot/install.c` uses no HAL and no OS.
- **Working directory:** run every command from the repository root.

## Review Focus

1. **A power cut inside any erase or program, including the app's own writes** (upload, PENDING, confirm, rollback) and every record write. The board must end on a valid confirmed image, never on halted rescue while a valid source exists. Pinned in Task 2, the `install` and `rollback` matrices (every operation, partial page and sector effects).
2. **The bootloader starting an image that fails its check:** half-written, the wrong one, or damaged in TRIAL. This must never happen. Pinned in Task 2, the harness check on every jump, `test_trial`, `test_silent_damage`.
3. **SPI4 failing for the records while the images are fine or half written** (rows 3–6): write failures, read failures, read timeouts, one-time errors, and power loss in the middle of the RAM path. Pinned in Task 2, `test_record_failures`, `test_record_read_errors`, `test_read_faults`.
4. **A fault that never reports an error:** a program that silently does nothing, or a slot changed after it was compared. Pinned in Task 2, `test_silent_damage`.
5. **Tests that pass without testing:** a corruption that only hits the header's unchecked padding, or a check whose code can be deleted unnoticed. Pinned in Task 2's `damage()` (asserts the image became invalid), and in Task 3, `mutants_ota.py` (20 mutants).

```c
// A NOR flash as the OTA code sees it (spec §5.2, §11.2): byte reads, 4 KB sector erase, programming
// within one 256-byte page. Implemented by the QSPI and SPI4 drivers on the board and by
// test/host/nor_sim.c on the host. Every wait inside an implementation has a deadline of twice
// the datasheet maximum (GD25Q32E Rev 1.3 §8.6: tSE 300 ms, tPP 2.4 ms) and kicks the watchdogs.
#pragma once
#include <stdint.h>

#define NOR_SECTOR 4096u
#define NOR_PAGE 256u

enum {
    NOR_OK = 0,
    NOR_TIMEOUT = -1,  // the device did not finish within its deadline
    NOR_EIO = -2,      // bus or controller error
};

typedef struct nor nor_t;
struct nor {
    int (*read)(nor_t *n, uint32_t off, void *buf, uint32_t len);
    int (*erase_sector)(nor_t *n, uint32_t off);                           // off is 4 KB aligned
    int (*program)(nor_t *n, uint32_t off, const void *buf, uint32_t len);  // within one page
    void *ctx;
};
```

Create `stm32/firmware/components/ota/include/ota_image.h`:

```c
// Image format and checks (spec §11.1). An image is a 1 KB header followed by the body, which starts
// with the vector table; it runs from QSPI_XIP_BASE with the body at QSPI_XIP_BASE + IMG_HDR_SIZE.
// Header layout (little endian), written by tools/mkimage.py:
//   0  magic "SBIO"          4  hardware id "SBIOT-H750", NUL padded to 16 bytes
//   20 version major, minor, patch (3 x u16), 0 (u16)
//   28 size: body bytes (u32) 32 SHA-256 of the body
//   64 CRC-32 of bytes 0..63 (u32)   68..1023 0xFF
#pragma once
#include <stdbool.h>
#include <stdint.h>
#include "nor.h"

#define IMG_HDR_SIZE 0x400u
#define IMG_CORE 68u  // the bytes that identify an image; the rest of the header is 0xFF
#define IMG_MAX_BODY (0x170000u - IMG_HDR_SIZE)

typedef struct {
    uint8_t raw[IMG_CORE];  // the header core as stored: compare two images with memcmp
    uint16_t version[3];
    uint32_t size;
    uint8_t sha256[32];
} img_hdr_t;

enum {
    IMG_OK = 0,
    IMG_EREAD = -1,     // flash read failed
    IMG_EMAGIC = -2,    // no image header (erased or foreign)
    IMG_ECRC = -3,      // header CRC wrong
    IMG_EHW = -4,       // built for another board
    IMG_ESIZE = -5,     // body empty or larger than the slot
    IMG_ESHA = -6,      // body does not match the header's SHA-256
    IMG_EVECTORS = -7,  // initial MSP or reset vector unusable
};

// Parses and checks the header core (magic, CRC, hardware id, size); fills h on success.
int img_parse(const uint8_t raw[IMG_CORE], img_hdr_t *h);
// Builds a header core (the C twin of mkimage.py, for the host tests).
void img_make(uint8_t raw[IMG_CORE], const uint16_t version[3], uint32_t size, const uint8_t sha256[32]);
// The two jump conditions of §11.1: MSP at the end of a stack in DTCM or AXI SRAM, Thumb reset
// vector inside [QSPI_XIP_BASE + IMG_HDR_SIZE, QSPI_XIP_BASE + IMG_HDR_SIZE + size).
bool img_vectors_ok(uint32_t msp, uint32_t reset, uint32_t size);
// Full check of the image at off on n: header, SHA-256 of the body, vectors. kick (may be NULL) is
// called between 4 KB chunks. Fills h (may be NULL) on IMG_OK.
int img_check(nor_t *n, uint32_t off, void (*kick)(void), img_hdr_t *h);
```

Create `stm32/firmware/test/host/nor_sim.h`:

```c
// Simulated NOR flash for the OTA host tests (spec §12.1): erase sets bytes to 0xFF, programming
// can only clear bits, and every erase and program is one operation in a counter shared by all
// devices of a world. Faults:
// - power cut at operation N: that operation is done only partly (a prefix of the page programmed,
//   a prefix of the sector erased, one byte in between half-done), then longjmp to w->cut_jmp;
// - timeout at operation N: the operation does nothing and returns NOR_TIMEOUT (a hung device);
// - up to two failing regions [lo, hi) of device dev, until cleared. code NOR_EIO / NOR_TIMEOUT:
//   every erase and program there fails so; SIM_SILENT: programming reports success but changes
//   nothing; SIM_READ_EIO / SIM_READ_TIMEOUT: reads there fail, erase and program work;
// - power cuts repeated: after the cut at cut_at, cuts_left more, each cut_period operations later;
// - a hook called once, before operation N or before the first operation on device hook_dev at an
//   offset >= hook_addr (to change memory or faults at a precise point).
#pragma once
#include <setjmp.h>
#include <stdint.h>
#include "nor.h"

#define SIM_SILENT 1        // fail code: a program that reports success but leaves the cells as they were
#define SIM_READ_EIO 2      // fail code: reads fail with NOR_EIO
#define SIM_READ_TIMEOUT 3  // fail code: reads fail with NOR_TIMEOUT

typedef struct sim_world sim_world_t;
struct sim_world {
    long ops;
    long cut_at, timeout_at, hook_at;  // -1: never
    int cuts_left;                     // further cuts after cut_at
    long cut_period;
    jmp_buf *cut_jmp;
    struct {
        int dev;  // 0 none, else the nor_sim id
        uint32_t lo, hi;
        int code;
        int count;  // > 0: the fault hits this many times, then clears itself; 0: until cleared
    } fail[2];
    int hook_dev;  // 0: hook by operation number only
    uint32_t hook_addr;
    void (*hook)(sim_world_t *w, void *arg);
    void *hook_arg;
    uint32_t rng;
};

typedef struct {
    nor_t nor;  // first: a nor_sim_t * is a nor_t *
    uint8_t *mem;
    uint32_t size;
    int id;
    sim_world_t *w;
} nor_sim_t;

void sim_world_init(sim_world_t *w, uint32_t seed);
void nor_sim_init(nor_sim_t *s, sim_world_t *w, int id, uint32_t size);  // all 0xFF
void nor_sim_free(nor_sim_t *s);
void sim_fail(sim_world_t *w, int i, int dev, uint32_t lo, uint32_t hi, int code);  // dev 0 clears
```

```c
#include <string.h>

static uint32_t rnd(sim_world_t *w)
{
    w->rng = w->rng * 1103515245u + 12345u;
    return w->rng >> 8;
}

void sim_world_init(sim_world_t *w, uint32_t seed)
{
    memset(w, 0, sizeof *w);
    w->cut_at = w->timeout_at = w->hook_at = -1;
    w->rng = seed ? seed : 1;
}

// Counts one operation; returns 1 (power cut: do it partly, then jump), 2 (timeout), or 0.
static int tick(nor_sim_t *s, uint32_t off)
{
    sim_world_t *w = s->w;
    long op = w->ops++;
    if (w->hook && (op == w->hook_at || (w->hook_dev == s->id && off >= w->hook_addr))) {
        void (*h)(sim_world_t *, void *) = w->hook;
        w->hook = 0;  // once
        h(w, w->hook_arg);
    }
    if (op == w->cut_at) {
        if (w->cuts_left > 0) {
            w->cuts_left--;
            w->cut_at = op + w->cut_period;
        }
        return 1;
    }
    if (op == w->timeout_at)
        return 2;
    for (int i = 0; i < 2; i++) {
        int c = w->fail[i].code;
        if (w->fail[i].dev == s->id && off >= w->fail[i].lo && off < w->fail[i].hi && c != SIM_READ_EIO &&
            c != SIM_READ_TIMEOUT)
            return c == NOR_TIMEOUT ? 2 : c == SIM_SILENT ? 4 : 3;
    }
    return 0;
}

static int sim_read(nor_t *n, uint32_t off, void *buf, uint32_t len)
{
    nor_sim_t *s = (nor_sim_t *)n;
    if (off > s->size || len > s->size - off)
        return NOR_EIO;
    for (int i = 0; i < 2; i++) {
        int c = s->w->fail[i].code;
        if (s->w->fail[i].dev == s->id && off < s->w->fail[i].hi && off + len > s->w->fail[i].lo &&
            (c == SIM_READ_EIO || c == SIM_READ_TIMEOUT)) {
            if (s->w->fail[i].count > 0 && --s->w->fail[i].count == 0)
                s->w->fail[i].dev = 0;
            return c == SIM_READ_TIMEOUT ? NOR_TIMEOUT : NOR_EIO;
        }
    }
    memcpy(buf, s->mem + off, len);
    return NOR_OK;
}

static int sim_erase(nor_t *n, uint32_t off)
{
    nor_sim_t *s = (nor_sim_t *)n;
    if (off % NOR_SECTOR || off >= s->size)
        return NOR_EIO;
    int t = tick(s, off);
    if (t == 2)
        return NOR_TIMEOUT;
    if (t == 3)
        return NOR_EIO;
    if (t == 4)
        t = 0;  // silent failures only affect programming
    if (t == 1) {
        uint32_t k = rnd(s->w) % NOR_SECTOR;
        memset(s->mem + off, 0xFF, k);
        s->mem[off + k] |= (uint8_t)rnd(s->w);  // half erased
        longjmp(*s->w->cut_jmp, 1);
    }
    memset(s->mem + off, 0xFF, NOR_SECTOR);
    return NOR_OK;
}

static int sim_program(nor_t *n, uint32_t off, const void *buf, uint32_t len)
{
    nor_sim_t *s = (nor_sim_t *)n;
    if (len == 0 || len > NOR_PAGE || off / NOR_PAGE != (off + len - 1) / NOR_PAGE || off + len > s->size)
        return NOR_EIO;
    int t = tick(s, off);
    if (t == 2)
        return NOR_TIMEOUT;
    if (t == 3)
        return NOR_EIO;
    if (t == 4)
        return NOR_OK;  // silent: nothing programmed
    const uint8_t *p = buf;
    uint32_t done = t == 1 ? rnd(s->w) % len : len;
    for (uint32_t i = 0; i < done; i++)
        s->mem[off + i] &= p[i];
    if (t == 1) {
        s->mem[off + done] &= (uint8_t)(p[done] | rnd(s->w));  // half programmed
        longjmp(*s->w->cut_jmp, 1);
    }
    return NOR_OK;
}

void nor_sim_init(nor_sim_t *s, sim_world_t *w, int id, uint32_t size)
{
    s->nor.read = sim_read;
    s->nor.erase_sector = sim_erase;
    s->nor.program = sim_program;
    s->nor.ctx = s;
    s->mem = malloc(size);
    memset(s->mem, 0xFF, size);
    s->size = size;
    s->id = id;
    s->w = w;
}

void sim_fail(sim_world_t *w, int i, int dev, uint32_t lo, uint32_t hi, int code)
{
    w->fail[i].dev = dev;
    w->fail[i].lo = lo;
    w->fail[i].hi = hi;
    w->fail[i].code = code;
    w->fail[i].count = 0;
}

void nor_sim_free(nor_sim_t *s)
{
    free(s->mem);
}
```

```c
#define ROR(x, n) (((x) >> (n)) | ((x) << (32 - (n))))

static void compress(uint32_t h[8], const uint8_t *p)
{
    uint32_t w[64];
    for (int i = 0; i < 16; i++)
        w[i] = (uint32_t)p[4 * i] << 24 | (uint32_t)p[4 * i + 1] << 16 | (uint32_t)p[4 * i + 2] << 8 | p[4 * i + 3];
    for (int i = 16; i < 64; i++) {
        uint32_t s0 = ROR(w[i - 15], 7) ^ ROR(w[i - 15], 18) ^ (w[i - 15] >> 3);
        uint32_t s1 = ROR(w[i - 2], 17) ^ ROR(w[i - 2], 19) ^ (w[i - 2] >> 10);
        w[i] = w[i - 16] + s0 + w[i - 7] + s1;
    }
    uint32_t a = h[0], b = h[1], c = h[2], d = h[3], e = h[4], f = h[5], g = h[6], k = h[7];
    for (int i = 0; i < 64; i++) {
        uint32_t t1 = k + (ROR(e, 6) ^ ROR(e, 11) ^ ROR(e, 25)) + ((e & f) ^ (~e & g)) + K[i] + w[i];
        uint32_t t2 = (ROR(a, 2) ^ ROR(a, 13) ^ ROR(a, 22)) + ((a & b) ^ (a & c) ^ (b & c));
        k = g;
        g = f;
        f = e;
        e = d + t1;
        d = c;
        c = b;
        b = a;
        a = t1 + t2;
    }
    h[0] += a;
    h[1] += b;
    h[2] += c;
    h[3] += d;
    h[4] += e;
    h[5] += f;
    h[6] += g;
    h[7] += k;
}

void sha256_init(sha256_t *s)
{
    static const uint32_t iv[8] = {0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a,
                                   0x510e527f, 0x9b05688c, 0x1f83d9ab, 0x5be0cd19};
    memcpy(s->h, iv, sizeof iv);
    s->bytes = 0;
    s->fill = 0;
}

void sha256_update(sha256_t *s, const void *data, size_t len)
{
    const uint8_t *p = data;
    s->bytes += len;
    while (len) {
        if (s->fill == 0 && len >= 64) {
            compress(s->h, p);
            p += 64;
            len -= 64;
            continue;
        }
        size_t n = 64 - s->fill < len ? 64 - s->fill : len;
        memcpy(s->block + s->fill, p, n);
        s->fill += (uint32_t)n;
        p += n;
        len -= n;
        if (s->fill == 64) {
            compress(s->h, s->block);
            s->fill = 0;
        }
    }
}

void sha256_final(sha256_t *s, uint8_t out[32])
{
    uint64_t bits = s->bytes * 8;
    uint8_t pad = 0x80;
    sha256_update(s, &pad, 1);
    pad = 0;
    while (s->fill != 56)
        sha256_update(s, &pad, 1);
    uint8_t len[8];
    for (int i = 0; i < 8; i++)
        len[i] = (uint8_t)(bits >> (56 - 8 * i));
    sha256_update(s, len, 8);
    for (int i = 0; i < 8; i++) {
        out[4 * i] = (uint8_t)(s->h[i] >> 24);
        out[4 * i + 1] = (uint8_t)(s->h[i] >> 16);
        out[4 * i + 2] = (uint8_t)(s->h[i] >> 8);
        out[4 * i + 3] = (uint8_t)s->h[i];
    }
}
```

```c
#include "ota_image.h"
#include <string.h>
#include "crc32.h"
#include "flashmap.h"
#include "sha256.h"

static const char k_magic[4] = {'S', 'B', 'I', 'O'};
static const char k_hw[16] = "SBIOT-H750";

static uint32_t le32(const uint8_t *p)
{
    return (uint32_t)p[0] | (uint32_t)p[1] << 8 | (uint32_t)p[2] << 16 | (uint32_t)p[3] << 24;
}

static void put32(uint8_t *p, uint32_t v)
{
    for (int i = 0; i < 4; i++)
        p[i] = (uint8_t)(v >> (8 * i));
}

int img_parse(const uint8_t raw[IMG_CORE], img_hdr_t *h)
{
    if (memcmp(raw, k_magic, 4))
        return IMG_EMAGIC;
    if (crc32_update(0, raw, 64) != le32(raw + 64))
        return IMG_ECRC;
    if (memcmp(raw + 4, k_hw, sizeof k_hw))
        return IMG_EHW;
    uint32_t size = le32(raw + 28);
    if (size < 8 || size > IMG_MAX_BODY)
        return IMG_ESIZE;
    memcpy(h->raw, raw, IMG_CORE);
    for (int i = 0; i < 3; i++)
        h->version[i] = (uint16_t)(raw[20 + 2 * i] | raw[21 + 2 * i] << 8);
    h->size = size;
    memcpy(h->sha256, raw + 32, 32);
    return IMG_OK;
}

void img_make(uint8_t raw[IMG_CORE], const uint16_t version[3], uint32_t size, const uint8_t sha256[32])
{
    memset(raw, 0, IMG_CORE);
    memcpy(raw, k_magic, 4);
    memcpy(raw + 4, k_hw, sizeof k_hw);
    for (int i = 0; i < 3; i++) {
        raw[20 + 2 * i] = (uint8_t)version[i];
        raw[21 + 2 * i] = (uint8_t)(version[i] >> 8);
    }
    put32(raw + 28, size);
    memcpy(raw + 32, sha256, 32);
    put32(raw + 64, crc32_update(0, raw, 64));
}

// An initial stack pointer is the end of the stack: above the region base, at most its end.
static bool in_ram(uint32_t sp, uint32_t base, uint32_t size)
{
    return sp > base && sp - base <= size;
}

bool img_vectors_ok(uint32_t msp, uint32_t reset, uint32_t size)
{
    bool msp_ok = (msp & 7u) == 0 && (in_ram(msp, 0x20000000u, 128u * 1024) || in_ram(msp, 0x24000000u, 512u * 1024));
    uint32_t pc = reset & ~1u, body = QSPI_XIP_BASE + IMG_HDR_SIZE;
    return msp_ok && (reset & 1u) && pc >= body && pc - body < size;
}

int img_check(nor_t *n, uint32_t off, void (*kick)(void), img_hdr_t *h)
{
    uint8_t raw[IMG_CORE];
    img_hdr_t hdr;
    if (n->read(n, off, raw, sizeof raw))
        return IMG_EREAD;
    int r = img_parse(raw, &hdr);
    if (r)
        return r;
    sha256_t s;
    sha256_init(&s);
    uint8_t buf[256];
    uint32_t vectors[2] = {0, 0};
    for (uint32_t done = 0; done < hdr.size;) {
        uint32_t len = hdr.size - done < sizeof buf ? hdr.size - done : (uint32_t)sizeof buf;
        if (n->read(n, off + IMG_HDR_SIZE + done, buf, len))
            return IMG_EREAD;
        if (done == 0)
            memcpy(vectors, buf, 8);  // size >= 8 (img_parse)
        sha256_update(&s, buf, len);
        done += len;
        if (kick && (done % NOR_SECTOR) == 0)
            kick();
    }
    uint8_t sha[32];
    sha256_final(&s, sha);
    if (memcmp(sha, hdr.sha256, 32))
        return IMG_ESHA;
    if (!img_vectors_ok(vectors[0], vectors[1], hdr.size))
        return IMG_EVECTORS;
    if (h)
        *h = hdr;
    return IMG_OK;
}
```

```python
#!/usr/bin/env python3
"""Fills the 1 KB image header (spec §11.1) of the app binary.

    python3 stm32/firmware/tools/mkimage.py --version 0.4.0 build/h750/app.bin build/h750/app.img

app.bin comes from objcopy of app.elf and starts at 0x90000000 with the header placeholder (1 KB
of 0xFF, app/image_header.c); the body (vector table first) follows at 0x90000400. The header
layout is the one components/ota/ota_image.h documents and img_parse() checks.
"""
import argparse
import hashlib
import struct
import sys
import zlib

HDR = 0x400
SLOT = 0x170000
XIP = 0x90000000
HW = b'SBIOT-H750'


def header(body, version):
    core = b'SBIO' + HW.ljust(16, b'\0') + struct.pack('<4H', *version, 0) + struct.pack('<I', len(body))
    core += hashlib.sha256(body).digest()
    core += struct.pack('<I', zlib.crc32(core))
    return core + b'\xff' * (HDR - len(core))


def vectors_ok(body):
    msp, reset = struct.unpack('<II', body[:8])
    in_ram = lambda sp, base, size: base < sp <= base + size
    msp_ok = msp % 8 == 0 and (in_ram(msp, 0x20000000, 128 * 1024) or in_ram(msp, 0x24000000, 512 * 1024))
    pc = reset & ~1
    return msp_ok and reset & 1 == 1 and XIP + HDR <= pc < XIP + HDR + len(body)


def make(data, version):
    """Returns the image, or raises ValueError with the reason."""
    if data[:HDR] != b'\xff' * HDR:
        raise ValueError('the first 1 KB is not the erased header placeholder (app/image_header.c)')
    body = data[HDR:]
    if not 8 <= len(body) <= SLOT - HDR:
        raise ValueError('body of %d bytes does not fit the %d-byte slot' % (len(body), SLOT))
    if not vectors_ok(body):
        raise ValueError('initial MSP or reset vector unusable')
    return header(body, version) + body


def main():
    ap = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    ap.add_argument('--version', required=True, help='major.minor.patch')
    ap.add_argument('bin')
    ap.add_argument('img')
    a = ap.parse_args()
    version = tuple(int(x) for x in a.version.split('.'))
    if len(version) != 3 or not all(0 <= v < 65536 for v in version):
        sys.exit('mkimage: version must be major.minor.patch')
    try:
        img = make(open(a.bin, 'rb').read(), version)
    except ValueError as e:
        sys.exit('mkimage: %s' % e)
    open(a.img, 'wb').write(img)
    print('mkimage: %s %s, body %d bytes, sha256 %s' % (a.img, a.version, len(img) - HDR,
                                                        hashlib.sha256(img[HDR:]).hexdigest()[:16]))


if __name__ == '__main__':
    main()
```

```c
// Boot state record (spec §11.2): two copies, A and B, each in its own 4 KB sector of SPI4. A write
// goes to the sector that does not hold the newest valid record: erase, body (page 0), then the
// CRC (page 1) last, so a cut write is never valid and the older record stays usable. The newest
// is the valid one with the larger seq in wrap-around order, (int32_t)(a - b) > 0.
#pragma once
#include <stdbool.h>
#include <stdint.h>
#include "nor.h"
#include "ota_image.h"

enum {
    BR_CONFIRMED = 1,
    BR_PENDING = 2,  // written by the app when staging holds a complete image
    BR_BACKUP = 3,   // copying QSPI -> backup, checkpoint `offset`
    BR_WRITE = 4,    // copying staging -> QSPI, checkpoint `offset`
    BR_VERIFY = 5,   // QSPI against the staging header
    BR_TRIAL = 6,    // the new image runs for the `trial`-th time and must confirm
    BR_RESTORE = 7,  // copying backup -> QSPI, checkpoint `offset`
};

// Why the last transition happened (logged by the app; spec §11.2 "lý do").
enum {
    RSN_NONE = 0,
    RSN_FIRST_BOOT,       // no valid record: created from what the flash holds
    RSN_STAGING_BAD,      // PENDING, but staging failed its check
    RSN_BACKUP_VERIFY,    // backup copy failed its SHA twice: install cancelled
    RSN_BACKUP_ABORTED,   // BACKUP attempts > 3: install cancelled
    RSN_QSPI_BAD,         // the running image failed its check
    RSN_BACKUP_BAD,       // RESTORE found no valid backup
    RSN_TRIAL_EXCEEDED,   // the new image never confirmed in 3 boots
    RSN_TRIAL_IMAGE_BAD,  // the new image failed its check before a trial boot
    RSN_APP_ROLLBACK,     // the app asked for RESTORE (a configured service failed to start)
    RSN_WRITE_EXHAUSTED,  // WRITE attempts or verifications used up
    RSN_INSTALLED,        // VERIFY passed
    RSN_RESTORED,         // RESTORE finished and verified
    RSN_CONFIRMED,        // the app confirmed the new image
    RSN_RESCUE_RETRY,     // rescue retried a recovery
};

typedef struct {
    uint32_t seq;
    uint8_t state;
    uint8_t offset;       // checkpoints (64 KB) done in BACKUP/WRITE/RESTORE
    uint8_t trial;        // trial boots started
    uint8_t attempts;     // starts of checkpoint `offset` not finished
    uint8_t verify_fail;  // failed VERIFY / post-RESTORE checks in this phase
    uint8_t degraded;     // the previous boot could not write the record
    uint8_t reason;       // RSN_*
    uint8_t staging[IMG_CORE];  // header core of the image being installed
    uint8_t backup[IMG_CORE];   // header core of the image in (or going to) backup
} bootrec_t;

// Reads both copies: BOOTREC_VALID with the newest valid one in r, BOOTREC_NONE when neither copy
// is valid, or a NOR error when a copy could not be read (then nothing is known about the state).
enum { BOOTREC_VALID = 1, BOOTREC_NONE = 0 };
int bootrec_read(nor_t *spi, bootrec_t *r);
// Writes r as the next record (r->seq is set to newest + 1). Returns NOR_OK, a NOR error, or
// NOR_EIO when the read-back does not match. Never writes when the newest copy cannot be
// determined (a read error), so a valid newest record is never erased. A failure before the CRC
// page is programmed leaves the previous record the newest; when only the read-back fails, the
// new record may have reached the flash intact and be the newest on the next read.
int bootrec_write(nor_t *spi, bootrec_t *r);
// For the tests: encodes r into the 512 bytes a slot holds (body page and CRC page).
void bootrec_encode(const bootrec_t *r, uint8_t out[512]);
```

```c
// Handoff block between bootloader and app (spec §11.2): 64 bytes at the end of backup SRAM, kept
// across resets while the board has power, lost on a power cycle (VBAT is tied to 3V3). A wrong
// magic or CRC (the first power-on) means all zero.
#pragma once
#include <stdint.h>

typedef struct {
    uint32_t magic;
    uint8_t rec_fail;   // consecutive boots that could not write the boot record
    uint8_t ram_fail;   // RAM-tracked recovery attempts (decision table row 6)
    uint8_t degraded;   // this boot runs without a writable record: the app refuses OTA (409)
    uint8_t reason;     // RSN_* of this boot's decision
    uint8_t pad[52];
    uint32_t crc;       // CRC-32 of the 60 bytes before it
} handoff_t;

_Static_assert(sizeof(handoff_t) == 64, "handoff block is 64 bytes");

void handoff_load(handoff_t *h);   // checks magic and CRC; resets to zero when wrong
void handoff_store(handoff_t *h);  // sets magic and CRC
```

```c
// OTA on the app side (spec §11.3): stream an image into staging and hand it to the bootloader,
// and confirm or roll back a new image. Used by POST /api/ota (Plan 06) and the UART7 bench
// upload (Plan 04b). Return codes map to the HTTP answers.
#pragma once
#include <stdbool.h>
#include <stdint.h>
#include "bootrec.h"
#include "handoff.h"
#include "nor.h"
#include "ota_image.h"
#include "sha256.h"

enum {
    OTA_OK = 0,
    OTA_EBUSY = -1,    // 409: the running image is not confirmed yet, or the record is not writable
    OTA_ETOOBIG = -2,  // 413: larger than the slot
    OTA_EIMAGE = -3,   // 400: not an image for this board, or its SHA-256 does not match
    OTA_ESHORT = -4,   // 400: the body ended before the size the header announced
    OTA_EFLASH = -5,   // 500: staging could not be erased, programmed or read back
};

typedef struct {
    nor_t *spi;
    uint32_t total;     // image bytes announced by the caller (header + body)
    uint32_t got;       // bytes received so far
    uint32_t erased;    // staging bytes erased so far (always a 4 KB multiple)
    uint8_t page[NOR_PAGE];
    uint32_t fill;      // bytes in page, not yet programmed
    img_hdr_t hdr;      // valid once got >= IMG_CORE
    sha256_t sha;       // over the body
    int error;          // sticky first error
} ota_stage_t;

// Starts an upload of `total` bytes. Refuses (OTA_EBUSY) unless the record says CONFIRMED (or there
// is none) and the boot was not degraded, so BACKUP can never overwrite the last good image; a
// record that cannot be read refuses with OTA_EFLASH.
int ota_stage_begin(ota_stage_t *st, nor_t *spi, const handoff_t *ho, uint32_t total);
// Takes the next chunk. Each 4 KB staging sector is erased just before the first byte lands in it.
// The header is checked as soon as its core has arrived (magic, CRC, hardware id, size == total).
int ota_stage_write(ota_stage_t *st, const void *data, uint32_t len);
// After the last chunk: SHA-256, vectors, a full read-back check of staging, then the PENDING
// record. Only then is the boot state changed.
int ota_stage_finish(ota_stage_t *st);

// TRIAL -> CONFIRMED (spec §11.3: all services up for 30 s). OTA_OK too when already CONFIRMED.
int ota_confirm(nor_t *spi);
// TRIAL -> RESTORE(0): a configured service failed to start.
int ota_rollback(nor_t *spi);
```

```c
// The bootloader's install and recovery logic (spec §11.2): one decision per boot from the boot
// state record, the three image sources and the handoff block. Plain C over nor_t, so the host
// tests run it on simulated flash with power cuts at every erase and program.
#pragma once
#include <stdbool.h>
#include <stdint.h>
#include "bootrec.h"
#include "handoff.h"
#include "nor.h"
#include "ota_image.h"

typedef enum {
    INSTALL_JUMP,          // run the image in QSPI; it passed img_check (degraded: no writable record)
    INSTALL_REBOOT,        // reset now and boot again (row 5; a checkpoint that failed its read-back)
    INSTALL_WATCHDOG,      // stop kicking and let IWDG1 reset the board (row 2: a copy missed its deadline)
    INSTALL_RESCUE_RETRY,  // blink fast, keep kicking, call install_rescue_retry() after 60 s
    INSTALL_RESCUE_HALT,   // blink fast, keep kicking, wait for SWD (row 1: no valid source left)
} install_result_t;

#define INSTALL_ROW(n) (1u << (n))  // decision-table rows in install_t.rows
#define INSTALL_BUG (1u << 31)      // the decision loop did not settle (never expected)

typedef struct {
    nor_t *qspi;            // the running image, offset QSPI_SLOT
    nor_t *spi;             // records, staging, backup (flashmap.h)
    handoff_t *ho;          // checked with handoff_load() by the caller
    void (*kick)(void);     // between chunks of long work (may be NULL)
    // results
    bool degraded;          // INSTALL_JUMP without a writable boot record
    uint32_t rows;          // INSTALL_ROW(n) for every decision-table row this call went through
    bootrec_t rec;          // the record as last read or written
    // private
    bool prev_degraded;
    signed char vq, vb, vs;  // validity cache: -1 unknown, else 0/1
    img_hdr_t hq, hb, hs;
} install_t;

install_result_t install_run(install_t *in);
// After INSTALL_RESCUE_RETRY and the 60 s pause: resets the counters and retries the recovery,
// from backup first, else from staging (spec §11.2, "Cứu hộ có thử lại").
install_result_t install_rescue_retry(install_t *in);
```

```c
// Host tests for the bootloader's install logic (spec §11.2, §12.1): make -C stm32/firmware/test/host
// Simulated QSPI and SPI4 (nor_sim), power cuts at every erase and program, deadlines, failing
// record sectors. Invariant checked on every boot: the bootloader never jumps into an image that
// fails img_check.
#include <setjmp.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "flashmap.h"
#include "install.h"
#include "nor_sim.h"
#include "ota_app.h"
#include "sha256.h"

static int failures;
#define CHECK(cond, ...)                                \
    do {                                                \
        if (!(cond)) {                                  \
            failures++;                                 \
            printf("FAIL %s:%d: ", __FILE__, __LINE__); \
            printf(__VA_ARGS__);                        \
            printf("\n");                               \
        }                                               \
    } while (0)

#define DEV_QSPI 1
#define DEV_SPI 2
#define BODY_V1 70000u  // 2 checkpoints with the header
#define BODY_V2 90000u

static uint32_t g_rows;  // decision-table rows seen over all tests

// ---- images -------------------------------------------------------------------------------

static uint8_t *make_image(uint16_t ver, uint32_t body, uint32_t *len)
{
    *len = IMG_HDR_SIZE + body;
    uint8_t *img = malloc(*len);
    memset(img, 0xFF, IMG_HDR_SIZE);
    uint8_t *b = img + IMG_HDR_SIZE;
    uint32_t x = ver * 2654435761u + body;
    for (uint32_t i = 0; i < body; i++) {
        x = x * 1664525u + 1013904223u;
        b[i] = (uint8_t)(x >> 24);
    }
    uint32_t msp = 0x20020000u, reset = QSPI_XIP_BASE + IMG_HDR_SIZE + (body > 0x200 ? 0x1E9u : 1u);
    memcpy(b, &msp, 4);
    memcpy(b + 4, &reset, 4);
    uint8_t sha[32];
    sha256_t s;
    sha256_init(&s);
    sha256_update(&s, b, body);
    sha256_final(&s, sha);
    uint16_t v[3] = {ver, 0, 0};
    img_make(img, v, body, sha);
    return img;
}

static void put_image(nor_sim_t *n, uint32_t off, uint16_t ver, uint32_t body)
{
    uint32_t len;
    uint8_t *img = make_image(ver, body, &len);
    memcpy(n->mem + off, img, len);
    free(img);
}

static void corrupt(nor_sim_t *n, uint32_t off)
{
    n->mem[off] ^= 0x5A;
}

static uint16_t version_at(nor_sim_t *n, uint32_t off)
{
    img_hdr_t h;
    return img_check(&n->nor, off, NULL, &h) == IMG_OK ? h.version[0] : 0;
}

// Damages the image at img_off: one body byte (the header's 0xFF padding is not checked by
// anything). When an image was there, it must now fail its check, or the test proves nothing.
static void damage(nor_sim_t *n, uint32_t img_off)
{
    bool was = version_at(n, img_off) != 0;
    n->mem[img_off + IMG_HDR_SIZE + 0x100] ^= 0x5A;
    if (was)
        CHECK(version_at(n, img_off) == 0, "damage at 0x%x left the image valid", (unsigned)img_off);
}

// ---- the bench ----------------------------------------------------------------------------

typedef struct {
    sim_world_t w;
    nor_sim_t q, s;
    handoff_t ho;
    jmp_buf jb;
    int boots, cuts, retries, trial_runs;
    uint32_t rows;
    uint8_t *upload_img;  // owned here: a power cut can longjmp out of upload()
} bench_t;

static void bench_init(bench_t *b, uint32_t seed)
{
    memset(b, 0, sizeof *b);
    sim_world_init(&b->w, seed);
    b->w.cut_jmp = &b->jb;
    nor_sim_init(&b->q, &b->w, DEV_QSPI, 0x400000);
    nor_sim_init(&b->s, &b->w, DEV_SPI, 0x400000);
    memset(&b->ho, 0xA5, sizeof b->ho);  // first power-on: garbage
}

static void bench_free(bench_t *b)
{
    g_rows |= b->rows;
    free(b->upload_img);
    nor_sim_free(&b->q);
    nor_sim_free(&b->s);
}

static void record(bench_t *b, uint8_t state, uint8_t offset, uint8_t attempts, uint8_t verify_fail, uint8_t trial,
                   uint16_t staging_ver, uint32_t staging_body, uint16_t backup_ver, uint32_t backup_body)
{
    bootrec_t r;
    memset(&r, 0, sizeof r);
    r.state = state;
    r.offset = offset;
    r.attempts = attempts;
    r.verify_fail = verify_fail;
    r.trial = trial;
    uint32_t len;
    if (staging_ver) {
        uint8_t *img = make_image(staging_ver, staging_body, &len);
        memcpy(r.staging, img, IMG_CORE);
        free(img);
    }
    if (backup_ver) {
        uint8_t *img = make_image(backup_ver, backup_body, &len);
        memcpy(r.backup, img, IMG_CORE);
        free(img);
    }
    long saved = b->w.ops;
    CHECK(bootrec_write(&b->s.nor, &r) == NOR_OK, "test record written");
    b->w.ops = saved;  // set-up writes do not count
}

// Uploads an image through the app's staging API (as POST /api/ota would). Returns the result.
static int upload(bench_t *b, uint16_t ver, uint32_t body)
{
    uint32_t len;
    free(b->upload_img);
    uint8_t *img = b->upload_img = make_image(ver, body, &len);
    ota_stage_t st;
    handoff_t ho = b->ho;
    handoff_load(&ho);
    int r = ota_stage_begin(&st, &b->s.nor, &ho, len);
    for (uint32_t i = 0; !r && i < len; i += 1000)
        r = ota_stage_write(&st, img + i, len - i < 1000 ? len - i : 1000);
    if (!r)
        r = ota_stage_finish(&st);
    return r;
}

enum { APP_CONFIRM, APP_CRASH, APP_ROLLBACK };
enum { OUT_RUN = 1, OUT_HALT, OUT_STUCK };

typedef struct {
    int kind;
    uint16_t version;
    bool degraded;
    uint8_t state;
} outcome_t;

// Boots until the app runs with nothing left to do, or the board stays in halted rescue. A power
// cut (longjmp out of any erase/program) loses the handoff block. A rescue retry is the 60 s pause.
static outcome_t boot_until_stable(bench_t *b, int policy, int max_boots)
{
    outcome_t o = {0};
    if (setjmp(b->jb)) {
        b->cuts++;
        memset(&b->ho, 0xA5, sizeof b->ho);  // power cut: backup SRAM lost
    }
    while (b->boots++ < max_boots) {
        handoff_load(&b->ho);
        install_t in = {.qspi = &b->q.nor, .spi = &b->s.nor, .ho = &b->ho};
        install_result_t r = install_run(&in);
        b->rows |= in.rows;
        while (r == INSTALL_RESCUE_RETRY && b->retries++ < 20) {
            r = install_rescue_retry(&in);
            b->rows |= in.rows;
        }
        CHECK(!(in.rows & INSTALL_BUG), "decision loop did not settle (rows %08x)", (unsigned)in.rows);
        if (r == INSTALL_RESCUE_RETRY) {
            o.kind = OUT_STUCK;
            return o;
        }
        if (r == INSTALL_RESCUE_HALT) {
            o.kind = OUT_HALT;
            return o;
        }
        if (r != INSTALL_JUMP)
            continue;  // REBOOT or WATCHDOG
        img_hdr_t h;
        int ok = img_check(&b->q.nor, QSPI_SLOT, NULL, &h);
        CHECK(ok == IMG_OK, "jumped into an image that fails its check (%d)", ok);
        if (ok != IMG_OK) {
            o.kind = OUT_STUCK;
            return o;
        }
        bootrec_t rec;
        bool have = bootrec_read(&b->s.nor, &rec) == BOOTREC_VALID;
        if (have && rec.state == BR_TRIAL && !in.degraded) {
            b->trial_runs++;
            if (policy == APP_CRASH)
                continue;  // the new image hangs before confirming: IWDG1 resets
            if (policy == APP_ROLLBACK) {
                ota_rollback(&b->s.nor);
                continue;
            }
            ota_confirm(&b->s.nor);
            have = bootrec_read(&b->s.nor, &rec) == BOOTREC_VALID;
        }
        o.kind = OUT_RUN;
        o.version = h.version[0];
        o.degraded = in.degraded;
        o.state = have ? rec.state : 0;
        return o;
    }
    o.kind = OUT_STUCK;
    return o;
}

// ---- plain cases ----------------------------------------------------------------------------

static void test_first_boot_and_blank(void)
{
    bench_t b;
    bench_init(&b, 1);
    put_image(&b.q, QSPI_SLOT, 1, BODY_V1);
    outcome_t o = boot_until_stable(&b, APP_CONFIRM, 5);
    CHECK(o.kind == OUT_RUN && o.version == 1 && o.state == BR_CONFIRMED, "first boot after SWD: v1 confirmed");
    bench_free(&b);

    bench_init(&b, 2);
    o = boot_until_stable(&b, APP_CONFIRM, 5);
    CHECK(o.kind == OUT_HALT, "blank flash: halted rescue (row 1)");
    bench_free(&b);

    bench_init(&b, 3);  // no record, QSPI bad, backup good
    put_image(&b.q, QSPI_SLOT, 1, BODY_V1);
    damage(&b.q, QSPI_SLOT);
    put_image(&b.s, SPI_BACKUP, 1, BODY_V1);
    o = boot_until_stable(&b, APP_CONFIRM, 10);
    CHECK(o.kind == OUT_RUN && o.version == 1 && o.state == BR_CONFIRMED, "no record, bad QSPI: restored from backup");
    bench_free(&b);

    bench_init(&b, 4);  // no record, only staging good
    put_image(&b.s, SPI_STAGING, 2, BODY_V2);

static void test_records(void)
{
    bench_t b;
    bench_init(&b, 5);
    put_image(&b.q, QSPI_SLOT, 1, BODY_V1);
    // seq wrap-around: a record with seq 0xFFFFFFFF, then the next write gets seq 0 and must win.
    bootrec_t r;
    memset(&r, 0, sizeof r);
    r.state = BR_CONFIRMED;
    uint8_t enc[512];
    r.seq = 0xFFFFFFFFu;
    bootrec_encode(&r, enc);
    memcpy(b.s.mem + SPI_REC_A, enc, sizeof enc);
    r.state = BR_TRIAL;
    CHECK(bootrec_write(&b.s.nor, &r) == NOR_OK && r.seq == 0, "seq wraps to 0");
    bootrec_t got;
    CHECK(bootrec_read(&b.s.nor, &got) == BOOTREC_VALID && got.state == BR_TRIAL && got.seq == 0, "seq 0 is newer than 0xFFFFFFFF");
    // both copies damaged: treated as no record
    corrupt(&b.s, SPI_REC_A + 10);
    corrupt(&b.s, SPI_REC_B + 10);
    CHECK(bootrec_read(&b.s.nor, &got) == BOOTREC_NONE, "both records damaged: none valid");
    outcome_t o = boot_until_stable(&b, APP_CONFIRM, 5);
    CHECK(o.kind == OUT_RUN && o.version == 1 && o.state == BR_CONFIRMED, "both records damaged: QSPI image confirmed");
    bench_free(&b);
}

static void test_handoff(void)
{
    handoff_t h;
    memset(&h, 0x3C, sizeof h);
    handoff_load(&h);
    CHECK(h.rec_fail == 0 && h.ram_fail == 0 && h.degraded == 0, "handoff with a bad CRC starts from zero");
    h.rec_fail = 2;
    handoff_store(&h);
    handoff_load(&h);
    CHECK(h.rec_fail == 2, "handoff survives a reset with its CRC");
    h.ram_fail = 1;  // changed without handoff_store: the magic is right, the CRC is not
    handoff_load(&h);
    CHECK(h.magic != 0 && h.rec_fail == 0 && h.ram_fail == 0, "handoff with the right magic but a wrong CRC starts from zero");
}

#define REC_LO SPI_REC_A
#define REC_HI (SPI_REC_B + NOR_SECTOR)

static void clear_faults(sim_world_t *w, void *arg)
{
    (void)arg;
    sim_fail(w, 0, 0, 0, 0, 0);
    sim_fail(w, 1, 0, 0, 0, 0);
}

static void clear_qspi_fault(sim_world_t *w, void *arg)
{
    (void)arg;
    sim_fail(w, 1, 0, 0, 0, 0);
}

static void start_handoff(bench_t *b, uint8_t rec_fail)
{
    handoff_load(&b->ho);
    b->ho.rec_fail = rec_fail;
    handoff_store(&b->ho);
}

static void test_deadlines(void)
{
    // A timeout in the middle of WRITE: row 2 (watchdog), counted, then the install finishes.
    bench_t b;
    bench_init(&b, 60);
    put_image(&b.q, QSPI_SLOT, 1, BODY_V1);
    boot_until_stable(&b, APP_CONFIRM, 3);
    upload(&b, 2, BODY_V2);
    b.w.timeout_at = b.w.ops + 500;
    outcome_t o = boot_until_stable(&b, APP_CONFIRM, 20);
    CHECK(o.kind == OUT_RUN && o.version == 2 && (b.rows & INSTALL_ROW(2)), "a missed deadline: watchdog reset, install finished");
    bench_free(&b);

    // QSPI erases always time out during WRITE: attempts run out, RESTORE fails too, rescue retries
    // until the fault goes away, then v1 is restored. Never a jump into a half image.
    bench_init(&b, 61);
    put_image(&b.q, QSPI_SLOT, 1, BODY_V1);
    boot_until_stable(&b, APP_CONFIRM, 3);
    upload(&b, 2, BODY_V2);
    sim_fail(&b.w, 0, DEV_QSPI, 0x10000, 0x20000, NOR_TIMEOUT);  // the second checkpoint hangs
    b.w.hook = clear_faults;
    b.w.hook_at = b.w.ops + 3000;
    o = boot_until_stable(&b, APP_CONFIRM, 60);
    CHECK(o.kind == OUT_RUN && o.version == 1 && (b.rows & INSTALL_ROW(2)) && (b.rows & INSTALL_ROW(8)),
          "QSPI hangs in WRITE: attempts run out (row 8), v1 restored once QSPI works (v%u rows %x)", o.version,
          (unsigned)b.rows);
    bench_free(&b);
}

// Hook before the last page of the copy: from now on the records fail, and the copy's source and
// the other slot are damaged (they were read already for every page but this last one's source).
static void break_everything_but_qspi(sim_world_t *w, void *arg)
{
    struct last { bench_t *b; uint32_t src; } *a = arg;
    sim_fail(w, 0, DEV_SPI, REC_LO, REC_HI, NOR_EIO);
    damage(&a->b->s, a->src);
    damage(&a->b->s, a->src == SPI_STAGING ? SPI_BACKUP : SPI_STAGING);
}

static void arm_backup_read_timeout(sim_world_t *w, void *arg)
{
    (void)arg;
    sim_fail(w, 1, DEV_SPI, SPI_BACKUP + 0x8000, SPI_BACKUP + 0x8100, SIM_READ_TIMEOUT);
}

static void test_record_failures(void)
{
    bench_t b;
    outcome_t o;
    // Row 4: records cannot be written, QSPI valid: run degraded, nothing erased.
    bench_init(&b, 70);
    put_image(&b.q, QSPI_SLOT, 1, BODY_V1);
    boot_until_stable(&b, APP_CONFIRM, 3);
    sim_fail(&b.w, 0, DEV_SPI, REC_LO, REC_HI, NOR_EIO);
    put_image(&b.s, SPI_STAGING, 2, BODY_V2);
    o = boot_until_stable(&b, APP_CONFIRM, 3);
    CHECK(o.kind == OUT_RUN && o.version == 1, "record not writable, no change needed: v1 runs");
    {
        // a PENDING written before the failure starts is postponed, and OTA is refused (409)
        bench_t c;
        bench_init(&c, 71);
        put_image(&c.q, QSPI_SLOT, 1, BODY_V1);
        boot_until_stable(&c, APP_CONFIRM, 3);
        upload(&c, 2, BODY_V2);
        sim_fail(&c.w, 0, DEV_SPI, REC_LO, REC_HI, NOR_EIO);
        o = boot_until_stable(&c, APP_CONFIRM, 3);
        CHECK(o.kind == OUT_RUN && o.version == 1 && o.degraded && (c.rows & INSTALL_ROW(4)), "row 4: degraded, install postponed");
        CHECK(c.ho.degraded == 1, "row 4: the app sees degraded");
        CHECK(upload(&c, 3, BODY_V1) == OTA_EBUSY, "row 4: OTA refused while degraded");
        bench_free(&c);
    }
    bench_free(&b);

    // Rows 5 then 6: during WRITE (QSPI half written) the records start failing; after 3 failed
    // boots the RAM-tracked path restores the backup and runs it degraded.
    bench_init(&b, 72);
    put_image(&b.s, SPI_STAGING, 2, BODY_V2);
    put_image(&b.s, SPI_BACKUP, 1, BODY_V1);
    put_image(&b.q, QSPI_SLOT, 2, BODY_V2);
    corrupt(&b.q, 0x10010);  // half written
    record(&b, BR_WRITE, 1, 1, 0, 0, 2, BODY_V2, 1, BODY_V1);
    sim_fail(&b.w, 0, DEV_SPI, REC_LO, REC_HI, NOR_TIMEOUT);  // a record timeout is row 3, not row 2
    o = boot_until_stable(&b, APP_CONFIRM, 10);
    CHECK(o.kind == OUT_RUN && o.version == 1 && o.degraded && (b.rows & INSTALL_ROW(5)) && (b.rows & INSTALL_ROW(6)),
          "rows 5, 6: RAM-tracked restore of the backup, degraded (v%u rows %x)", o.version, (unsigned)b.rows);
    bench_free(&b);

    // Row 6 with a bad backup: falls back to staging (step 4 drops the bad source).
    bench_init(&b, 73);
    put_image(&b.s, SPI_STAGING, 2, BODY_V2);
    put_image(&b.s, SPI_BACKUP, 1, BODY_V1);
    damage(&b.s, SPI_BACKUP);
    record(&b, BR_WRITE, 1, 1, 0, 0, 2, BODY_V2, 1, BODY_V1);
    sim_fail(&b.w, 0, DEV_SPI, REC_LO, REC_HI, NOR_EIO);
    start_handoff(&b, 2);
    o = boot_until_stable(&b, APP_CONFIRM, 10);
    CHECK(o.kind == OUT_RUN && o.version == 2 && o.degraded, "row 6: bad backup skipped, staging copied");
    bench_free(&b);

    // Row 6, the RAM copy misses its deadline: watchdog, counted in ram_fail; after 3 the rescue
    // retry takes over; once QSPI works again the recovery succeeds. Records fail throughout.
    bench_init(&b, 74);
    put_image(&b.s, SPI_BACKUP, 1, BODY_V1);
    record(&b, BR_RESTORE, 1, 1, 0, 0, 0, 0, 1, BODY_V1);
    start_handoff(&b, 2);
    sim_fail(&b.w, 0, DEV_SPI, REC_LO, REC_HI, NOR_EIO);
    sim_fail(&b.w, 1, DEV_QSPI, 0, 0x400000, NOR_TIMEOUT);
    b.w.hook = clear_qspi_fault;
    b.w.hook_at = b.w.ops + 12;  // two operations per boot: about five boots of hanging QSPI
    o = boot_until_stable(&b, APP_CONFIRM, 20);
    CHECK(o.kind == OUT_RUN && o.version == 1 && o.degraded && (b.rows & INSTALL_ROW(2)) && b.retries > 0,
          "row 6: deadline, ram_fail > 3, rescue retry, then restored (v%u rows %x retries %d)", o.version,
          (unsigned)b.rows, b.retries);
    bench_free(&b);

    // Row 6, power lost in the middle of the RAM copy: the handoff block goes with it (rec_fail and
    // ram_fail back to 0), and the next boots work their way to the RAM path again.
    bench_init(&b, 76);
    put_image(&b.s, SPI_BACKUP, 1, BODY_V1);
    record(&b, BR_RESTORE, 1, 1, 0, 0, 0, 0, 1, BODY_V1);
    start_handoff(&b, 2);
    sim_fail(&b.w, 0, DEV_SPI, REC_LO, REC_HI, NOR_EIO);
    b.w.cut_at = b.w.ops + 30;  // inside the RAM copy (after the failed record write)
    o = boot_until_stable(&b, APP_CONFIRM, 20);
    CHECK(o.kind == OUT_RUN && o.version == 1 && o.degraded, "row 6: power cut during the RAM copy, then restored");
    bench_free(&b);

    // Row 4, special case: WRITE copies its last checkpoint, then the record update fails, while
    // staging and backup are both damaged. QSPI holds the only valid image: run it degraded, do not
    // erase it, do not halt. Same for RESTORE.
    for (int restore = 0; restore < 2; restore++) {
        bench_init(&b, 77 + restore);
        uint32_t src = restore ? SPI_BACKUP : SPI_STAGING;
        put_image(&b.s, src, 2, BODY_V2);
        put_image(&b.q, QSPI_SLOT, 2, BODY_V2);  // checkpoint 0 done ...
        corrupt(&b.q, 0x10100);                  // ... checkpoint 1 not yet
        if (restore)
            record(&b, BR_RESTORE, 1, 0, 0, 0, 0, 0, 2, BODY_V2);
        else
            record(&b, BR_WRITE, 1, 0, 0, 0, 2, BODY_V2, 0, 0);
        struct last { bench_t *b; uint32_t src; } arg = {&b, src};
        b.w.hook = break_everything_but_qspi;
        b.w.hook_arg = &arg;
        b.w.hook_dev = DEV_QSPI;
        b.w.hook_addr = (IMG_HDR_SIZE + BODY_V2 - 1) & ~(NOR_PAGE - 1);  // the last page of the image
        o = boot_until_stable(&b, APP_CONFIRM, 5);
        CHECK(o.kind == OUT_RUN && o.version == 2 && o.degraded && (b.rows & INSTALL_ROW(4)),
              "%s: last checkpoint done, record fails, only QSPI valid: degraded run", restore ? "RESTORE" : "WRITE");
        CHECK(version_at(&b.q, QSPI_SLOT) == 2, "and QSPI still holds the image");
        bench_free(&b);
    }
}

typedef struct {
    const char *name;
    int policy;
    uint16_t want;        // the image expected at the end when the cut came after PENDING
} matrix_t;

// One run: v1 confirmed, the app uploads v2 (PENDING), boots until stable. cut < 0: no cut.
// Returns the number of operations of the whole run and fills o / pending_done.
// The bench lives on the heap: it changes between setjmp and longjmp, and a local object would be
// indeterminate afterwards (C11 7.13.2.1p3). cuts > 1 adds cuts every `period` operations.
static long one_run(const matrix_t *m, long cut, int cuts, long period, outcome_t *o, long *pending_done)
{
    bench_t *b = malloc(sizeof *b);
    bench_init(b, 1000 + (uint32_t)cut * 7 + (uint32_t)period);
    put_image(&b->q, QSPI_SLOT, 1, BODY_V1);
    boot_until_stable(b, APP_CONFIRM, 3);
    b->w.ops = 0;
    b->w.cut_at = cut;
    b->w.cuts_left = cuts - 1;
    b->w.cut_period = period;
    if (!setjmp(b->jb)) {
        upload(b, 2, BODY_V2);
        if (pending_done)
            *pending_done = b->w.ops;
    } else {
        memset(&b->ho, 0xA5, sizeof b->ho);
    }
    b->boots = 0;
    *o = boot_until_stable(b, m->policy, 60);
    long ops = b->w.ops;
    bench_free(b);
    free(b);
    return ops;
}

static void test_power_cuts(const matrix_t *m)
{
    outcome_t o;
    long pending = 0;
    long total = one_run(m, -1, 1, 0, &o, &pending);
    CHECK(o.kind == OUT_RUN && o.version == m->want && o.state == BR_CONFIRMED, "%s without cuts", m->name);
    int bad = 0, newer = 0;
    for (long cut = 0; cut < total; cut++) {
        one_run(m, cut, 1, 0, &o, NULL);
        bool ok = o.kind == OUT_RUN && o.state == BR_CONFIRMED && !o.degraded && (o.version == 1 || o.version == 2);
        if (cut >= pending)
            ok = ok && o.version == m->want;  // one cut after PENDING costs an attempt, never the install
        if (!ok && bad++ < 5)
            printf("  %s: cut at op %ld/%ld -> kind %d v%u state %u degraded %d\n", m->name, cut, total, o.kind,
                   o.version, o.state, o.degraded);
        newer += o.version == 2;
    }
    CHECK(bad == 0, "%s: %d of %ld cut points end wrong", m->name, bad, total);
    printf("%s: %ld cut points (PENDING done at op %ld), %d ended on v2\n", m->name, total, pending, newer);

    // Several cuts in one run: three cuts at a random start, a random 1-200 operations apart. With
    // repeated cuts both images are acceptable; never a halt, a degraded run or an unconfirmed end.
    uint32_t x = 12345;
    bad = 0;
    for (int i = 0; i < 300; i++) {
        x = x * 1103515245u + 12345u;
        long cut = (long)((x >> 8) % (uint32_t)total), period = 1 + (long)((x >> 4) % 200);
        one_run(m, cut, 3, period, &o, NULL);
        bool ok = o.kind == OUT_RUN && o.state == BR_CONFIRMED && !o.degraded && (o.version == 1 || o.version == 2);
        if (!ok && bad++ < 5)
            printf("  %s: 3 cuts from op %ld every %ld -> kind %d v%u state %u\n", m->name, cut, period, o.kind,
                   o.version, o.state);
    }
    CHECK(bad == 0, "%s: %d of 300 triple-cut runs end wrong", m->name, bad);
}
```

```c
#include "bootrec.h"
#include <string.h>
#include "crc32.h"
#include "flashmap.h"

#define REC_MAGIC 0x43455242u  // "BREC"
#define BODY_LEN (16 + 2 * IMG_CORE)

static void put32(uint8_t *p, uint32_t v)
{
    for (int i = 0; i < 4; i++)
        p[i] = (uint8_t)(v >> (8 * i));
}

static uint32_t le32(const uint8_t *p)
{
    return (uint32_t)p[0] | (uint32_t)p[1] << 8 | (uint32_t)p[2] << 16 | (uint32_t)p[3] << 24;
}

static void encode_body(const bootrec_t *r, uint8_t b[BODY_LEN])
{
    put32(b, REC_MAGIC);
    put32(b + 4, r->seq);
    uint8_t f[8] = {r->state, r->offset, r->trial, r->attempts, r->verify_fail, r->degraded, r->reason, 0};
    memcpy(b + 8, f, 8);
    memcpy(b + 16, r->staging, IMG_CORE);
    memcpy(b + 16 + IMG_CORE, r->backup, IMG_CORE);
}

void bootrec_encode(const bootrec_t *r, uint8_t out[512])
{
    memset(out, 0xFF, 512);
    encode_body(r, out);
    put32(out + 256, crc32_update(0, out, BODY_LEN));
    put32(out + 260, REC_MAGIC);
}

static bool decode(const uint8_t b[512], bootrec_t *r)
{
    if (le32(b) != REC_MAGIC || le32(b + 260) != REC_MAGIC || crc32_update(0, b, BODY_LEN) != le32(b + 256))
        return false;
    if (b[8] < BR_CONFIRMED || b[8] > BR_RESTORE)
        return false;
    r->seq = le32(b + 4);
    r->state = b[8];
    r->offset = b[9];
    r->trial = b[10];
    r->attempts = b[11];
    r->verify_fail = b[12];
    r->degraded = b[13];
    r->reason = b[14];
    memcpy(r->staging, b + 16, IMG_CORE);
    memcpy(r->backup, b + 16 + IMG_CORE, IMG_CORE);
    return true;
}

// 1 valid, 0 invalid, < 0 read error
static int read_slot(nor_t *spi, uint32_t off, bootrec_t *r)
{
    uint8_t b[512];
    int e = spi->read(spi, off, b, sizeof b);
    return e ? e : decode(b, r);
}

static bool newer(uint32_t a, uint32_t b)
{
    return (int32_t)(a - b) > 0;
}

// Which slot holds the newest record (*at = SPI_REC_A or SPI_REC_B, 0 when neither is valid);
// returns a NOR error when either copy cannot be read.
static int newest(nor_t *spi, bootrec_t *r, uint32_t *at)
{
    bootrec_t a, b;
    int va = read_slot(spi, SPI_REC_A, &a), vb = read_slot(spi, SPI_REC_B, &b);
    if (va < 0)
        return va;
    if (vb < 0)
        return vb;
    *at = 0;
    if (va && (!vb || !newer(b.seq, a.seq))) {
        *r = a;
        *at = SPI_REC_A;
    } else if (vb) {
        *r = b;
        *at = SPI_REC_B;
    }
    return NOR_OK;
}

int bootrec_read(nor_t *spi, bootrec_t *r)
{
    uint32_t at;
    int e = newest(spi, r, &at);
    return e ? e : at ? BOOTREC_VALID : BOOTREC_NONE;
}

int bootrec_write(nor_t *spi, bootrec_t *r)
{
    bootrec_t cur;
    uint32_t at;
    int e = newest(spi, &cur, &at);
    if (e)
        return e;
    uint32_t slot = at == SPI_REC_A ? SPI_REC_B : SPI_REC_A;
    r->seq = at ? cur.seq + 1 : 1;
    uint8_t b[512], back[512];
    bootrec_encode(r, b);
    e = spi->erase_sector(spi, slot);
    if (!e)
        e = spi->program(spi, slot, b, NOR_PAGE);  // body first
    if (!e)
        e = spi->program(spi, slot + NOR_PAGE, b + NOR_PAGE, NOR_PAGE);  // the CRC page last
    if (!e)
        e = spi->read(spi, slot, back, sizeof back);
    if (!e && memcmp(b, back, sizeof b))
        e = NOR_EIO;
    return e;
}
```

```c
#include "handoff.h"
#include <stddef.h>
#include <string.h>
#include "crc32.h"

#define HANDOFF_MAGIC 0x46464F48u  // "HOFF"

void handoff_load(handoff_t *h)
{
    if (h->magic != HANDOFF_MAGIC || h->crc != crc32_update(0, h, offsetof(handoff_t, crc))) {
        memset(h, 0, sizeof *h);
        handoff_store(h);
    }
}

void handoff_store(handoff_t *h)
{
    h->magic = HANDOFF_MAGIC;
    h->crc = crc32_update(0, h, offsetof(handoff_t, crc));
}
```

```c
#include "ota_app.h"
#include <string.h>
#include "flashmap.h"

static int fail(ota_stage_t *st, int e)
{
    if (!st->error)
        st->error = e;
    return st->error;
}

int ota_stage_begin(ota_stage_t *st, nor_t *spi, const handoff_t *ho, uint32_t total)
{
    memset(st, 0, sizeof *st);
    st->spi = spi;
    st->total = total;
    bootrec_t r;
    int rr = bootrec_read(spi, &r);
    if (rr < 0)
        return fail(st, OTA_EFLASH);  // the boot state is unknown: never start an upload
    if (ho->degraded || (rr == BOOTREC_VALID && r.state != BR_CONFIRMED))
        return fail(st, OTA_EBUSY);
    if (total > SLOT_SIZE)
        return fail(st, OTA_ETOOBIG);
    if (total < IMG_HDR_SIZE + 8)
        return fail(st, OTA_EIMAGE);
    sha256_init(&st->sha);
    return OTA_OK;
}

static int flush_page(ota_stage_t *st)
{
    uint32_t at = st->got - st->fill;  // image offset of page[0]; a page boundary
    while (st->erased < at + st->fill) {
        if (st->spi->erase_sector(st->spi, SPI_STAGING + st->erased))
            return fail(st, OTA_EFLASH);
        st->erased += NOR_SECTOR;
    }
    if (st->spi->program(st->spi, SPI_STAGING + at, st->page, st->fill))
        return fail(st, OTA_EFLASH);
    st->fill = 0;
    return OTA_OK;
}

int ota_stage_write(ota_stage_t *st, const void *data, uint32_t len)
{
    const uint8_t *p = data;
    if (st->error)
        return st->error;
    if (len > st->total - st->got)
        return fail(st, OTA_ETOOBIG);
    while (len) {
        uint32_t n = NOR_PAGE - st->fill < len ? NOR_PAGE - st->fill : len;
        memcpy(st->page + st->fill, p, n);
        uint32_t before = st->got;
        st->fill += n;
        st->got += n;
        if (before < IMG_CORE && st->got >= IMG_CORE) {  // the header core is complete: page[0..67]
            if (img_parse(st->page, &st->hdr) != IMG_OK)
                return fail(st, OTA_EIMAGE);
            if (IMG_HDR_SIZE + st->hdr.size != st->total)
                return fail(st, OTA_EIMAGE);
        }
        // the body starts at IMG_HDR_SIZE, a page boundary
        if (st->got > IMG_HDR_SIZE) {
            uint32_t body_from = before > IMG_HDR_SIZE ? before : IMG_HDR_SIZE;
            sha256_update(&st->sha, st->page + (body_from - (st->got - st->fill)), st->got - body_from);
        }
        if (st->fill == NOR_PAGE && flush_page(st))
            return st->error;
        p += n;
        len -= n;
    }
    return OTA_OK;
}

int ota_stage_finish(ota_stage_t *st)
{
    if (st->error)
        return st->error;
    if (st->got < st->total)
        return fail(st, OTA_ESHORT);
    if (st->fill && flush_page(st))
        return st->error;
    uint8_t sha[32];
    sha256_final(&st->sha, sha);
    if (memcmp(sha, st->hdr.sha256, 32))
        return fail(st, OTA_EIMAGE);
    // What the bootloader will check, read back from staging itself (catches programming errors).
    img_hdr_t back;
    int r = img_check(st->spi, SPI_STAGING, 0, &back);
    if (r == IMG_EVECTORS)
        return fail(st, OTA_EIMAGE);
    if (r != IMG_OK || memcmp(back.raw, st->hdr.raw, IMG_CORE))
        return fail(st, OTA_EFLASH);
    bootrec_t rec;
    int rr = bootrec_read(st->spi, &rec);
    if (rr < 0)
        return fail(st, OTA_EFLASH);
    if (rr == BOOTREC_NONE)
        memset(&rec, 0, sizeof rec);
    rec.state = BR_PENDING;
    rec.offset = rec.attempts = rec.verify_fail = rec.trial = 0;
    rec.reason = RSN_NONE;
    memcpy(rec.staging, st->hdr.raw, IMG_CORE);
    return bootrec_write(st->spi, &rec) == NOR_OK ? OTA_OK : fail(st, OTA_EFLASH);
}

int ota_confirm(nor_t *spi)
{
    bootrec_t r;
    if (bootrec_read(spi, &r) != BOOTREC_VALID)
        return OTA_EFLASH;
    if (r.state == BR_CONFIRMED)
        return OTA_OK;
    if (r.state != BR_TRIAL)
        return OTA_EBUSY;
    r.state = BR_CONFIRMED;
    r.offset = r.attempts = r.verify_fail = 0;
    r.reason = RSN_CONFIRMED;
    return bootrec_write(spi, &r) == NOR_OK ? OTA_OK : OTA_EFLASH;
}

int ota_rollback(nor_t *spi)
{
    bootrec_t r;
    if (bootrec_read(spi, &r) != BOOTREC_VALID)
        return OTA_EFLASH;
    if (r.state != BR_TRIAL)
        return OTA_EBUSY;
    r.state = BR_RESTORE;
    r.offset = r.attempts = r.verify_fail = 0;
    r.reason = RSN_APP_ROLLBACK;
    return bootrec_write(spi, &r) == NOR_OK ? OTA_OK : OTA_EFLASH;
}
```

Create `stm32/firmware/boot/install.c`:

```c
#include "install.h"
#include <string.h>
#include "flashmap.h"

#define CONTINUE (-1)  // a step changed the record and the decision loop goes round again
#define COPY_MISMATCH (-100)

static uint32_t image_len(const uint8_t core[IMG_CORE])
{
    uint32_t size = (uint32_t)core[28] | (uint32_t)core[29] << 8 | (uint32_t)core[30] << 16 | (uint32_t)core[31] << 24;
    return IMG_HDR_SIZE + size;
}

static uint32_t checkpoints(uint32_t len)
{
    return (len + CHECKPOINT - 1) / CHECKPOINT;
}

// ---- the three sources, checked on demand and cached until written --------------------------

static bool check(install_t *in, signed char *v, img_hdr_t *h, nor_t *n, uint32_t off)
{
    if (*v < 0)
        *v = img_check(n, off, in->kick, h) == IMG_OK;
    return *v;
}

static bool vq(install_t *in) { return check(in, &in->vq, &in->hq, in->qspi, QSPI_SLOT); }
static bool vb(install_t *in) { return check(in, &in->vb, &in->hb, in->spi, SPI_BACKUP); }
static bool vs(install_t *in) { return check(in, &in->vs, &in->hs, in->spi, SPI_STAGING); }

// ---- the record --------------------------------------------------------------------------

static void set_state(install_t *in, uint8_t state, uint8_t reason)
{
    in->rec.state = state;
    in->rec.offset = 0;
    in->rec.attempts = 0;
    in->rec.reason = reason;
}

static void enter_restore(install_t *in, uint8_t reason)
{
    set_state(in, BR_RESTORE, reason);
    in->rec.verify_fail = 0;
    if (vb(in))
        memcpy(in->rec.backup, in->hb.raw, IMG_CORE);
}

static bool put(install_t *in)
{
    in->rec.degraded = in->prev_degraded;
    if (bootrec_write(in->spi, &in->rec) != NOR_OK)
        return false;
    if (in->ho->rec_fail) {
        in->ho->rec_fail = 0;
        handoff_store(in->ho);
    }
    return true;
}

static install_result_t jump(install_t *in, bool degraded)
{
    in->degraded = degraded;
    in->ho->degraded = degraded;
    in->ho->reason = in->rec.reason;
    handoff_store(in->ho);
    return INSTALL_JUMP;
}

// ---- copying -------------------------------------------------------------------------------

// Checkpoint k of an image of len bytes: erase the 4 KB sectors it covers (the last one rounded up,
// spec §5.2), program page by page, read back and compare with the source.
static int copy_checkpoint(install_t *in, nor_t *src, uint32_t so, nor_t *dst, uint32_t dof, uint32_t len, uint32_t k)
{
    uint32_t start = k * CHECKPOINT, end = start + CHECKPOINT < len ? start + CHECKPOINT : len;
    for (uint32_t s = start; s < end; s += NOR_SECTOR) {
        int e = dst->erase_sector(dst, dof + s);
        if (e)
            return e;
        if (in->kick)
            in->kick();
    }
    uint8_t buf[NOR_PAGE], back[NOR_PAGE];
    for (uint32_t p = start; p < end; p += NOR_PAGE) {
        uint32_t n = end - p < NOR_PAGE ? end - p : NOR_PAGE;
        int e = src->read(src, so + p, buf, n);
        if (e)
            return e;  // a read timeout stays a timeout (row 2)
        e = dst->program(dst, dof + p, buf, n);
        if (e)
            return e;
        e = dst->read(dst, dof + p, back, n);
        if (e)
            return e;
        if (memcmp(buf, back, n))
            return COPY_MISMATCH;
    }
    return NOR_OK;
}

static install_result_t rec_failed(install_t *in);

// Runs the remaining checkpoints of the current BACKUP/WRITE/RESTORE. Each start is counted in the
// record before it begins, so a reset in the middle is counted too (spec §11.2).
static int run_copy(install_t *in, nor_t *src, uint32_t so, nor_t *dst, uint32_t dof, uint32_t len, signed char *dst_valid)
{
    while (in->rec.offset < checkpoints(len)) {
        in->rec.attempts++;
        if (!put(in))
            return rec_failed(in);
        int e = copy_checkpoint(in, src, so, dst, dof, len, in->rec.offset);
        *dst_valid = -1;
        if (e == NOR_TIMEOUT) {
            in->rows |= INSTALL_ROW(2);
            return INSTALL_WATCHDOG;
        }
        if (e)
            return INSTALL_REBOOT;  // counted in attempts; rows 7-9 stop the loop
        in->rec.offset++;
        in->rec.attempts = 0;
        if (!put(in))
            return rec_failed(in);
    }
    return CONTINUE;
}

// ---- rows 3-6 and the RAM-tracked recovery ----------------------------------------------------

static install_result_t ram_path(install_t *in)
{
    in->rows |= INSTALL_ROW(6);
    if (in->ho->ram_fail < 255)
        in->ho->ram_fail++;  // counted before anything else
    handoff_store(in->ho);
    if (in->ho->ram_fail > 3)
        return INSTALL_RESCUE_RETRY;
    const uint32_t sources[2] = {SPI_BACKUP, SPI_STAGING};
    for (int i = 0; i < 2; i++) {
        img_hdr_t h;
        if (img_check(in->spi, sources[i], in->kick, &h) != IMG_OK)
            continue;  // a bad source never gets copied; try the next one
        uint32_t len = IMG_HDR_SIZE + h.size;
        for (uint32_t k = 0; k < checkpoints(len); k++) {
            int e = copy_checkpoint(in, in->spi, sources[i], in->qspi, QSPI_SLOT, len, k);
            in->vq = -1;
            if (e == NOR_TIMEOUT) {
                in->rows |= INSTALL_ROW(2);
                return INSTALL_WATCHDOG;
            }
            if (e)
                break;
        }
        if (vq(in)) {
            in->ho->ram_fail = 0;
            handoff_store(in->ho);
            return jump(in, true);
        }
        return INSTALL_REBOOT;  // never jump into an image that failed its check
    }
    in->rows |= INSTALL_ROW(1);
    return INSTALL_RESCUE_HALT;
}

static install_result_t rec_failed(install_t *in)
{
    in->rows |= INSTALL_ROW(3);
    if (in->ho->rec_fail < 255)
        in->ho->rec_fail++;
    handoff_store(in->ho);
    if (vq(in)) {
        in->rows |= INSTALL_ROW(4);
        return jump(in, true);  // QSPI is never erased here; a pending install waits
    }
    if (in->ho->rec_fail < 3) {
        in->rows |= INSTALL_ROW(5);
        return INSTALL_REBOOT;
    }
    return ram_path(in);
}

// ---- row 10: one step of the state machine ----------------------------------------------------

static int step(install_t *in)
{
    bootrec_t *r = &in->rec;
    int res;
    switch (r->state) {
    case BR_CONFIRMED:
        if (vq(in))
            return jump(in, false);
        if (vb(in)) {
            enter_restore(in, RSN_QSPI_BAD);
            break;
        }
        in->rows |= INSTALL_ROW(9);  // only staging is left (row 1 covered none)
        return INSTALL_RESCUE_RETRY;
    case BR_PENDING:
        r->verify_fail = 0;
        if (!vs(in)) {
            set_state(in, BR_CONFIRMED, RSN_STAGING_BAD);  // checked before anything is erased
            break;
        }
        memcpy(r->staging, in->hs.raw, IMG_CORE);
        if (vq(in)) {
            memcpy(r->backup, in->hq.raw, IMG_CORE);
            set_state(in, BR_BACKUP, RSN_NONE);
        } else {
            set_state(in, BR_WRITE, RSN_NONE);  // the running image is bad: keep the old backup
        }
        break;
    case BR_BACKUP:
        res = run_copy(in, in->qspi, QSPI_SLOT, in->spi, SPI_BACKUP, image_len(r->backup), &in->vb);
        if (res != CONTINUE)
            return res;
        if (vb(in) && !memcmp(in->hb.raw, r->backup, IMG_CORE)) {
            set_state(in, BR_WRITE, RSN_NONE);
            r->verify_fail = 0;
        } else if (++r->verify_fail >= 2) {
            set_state(in, BR_CONFIRMED, RSN_BACKUP_VERIFY);  // the running image is untouched
            r->verify_fail = 0;
        } else {
            set_state(in, BR_BACKUP, RSN_NONE);
        }
        break;
    case BR_WRITE:
        res = run_copy(in, in->spi, SPI_STAGING, in->qspi, QSPI_SLOT, image_len(r->staging), &in->vq);
        if (res != CONTINUE)
            return res;
        set_state(in, BR_VERIFY, RSN_NONE);
        break;
    case BR_VERIFY:
        if (vq(in) && !memcmp(in->hq.raw, r->staging, IMG_CORE)) {
            set_state(in, BR_TRIAL, RSN_INSTALLED);
            r->trial = 0;
            r->verify_fail = 0;
        } else {
            r->verify_fail++;
            set_state(in, BR_WRITE, RSN_NONE);
        }
        break;
    case BR_TRIAL:
        if (r->trial + 1 > 3) {
            enter_restore(in, RSN_TRIAL_EXCEEDED);
            break;
        }
        if (!vq(in)) {
            enter_restore(in, RSN_TRIAL_IMAGE_BAD);  // never jump into a bad image, even in TRIAL
            break;
        }
        r->trial++;
        if (!put(in))
            return rec_failed(in);  // row 4: runs degraded, cannot confirm; the trial counts only if
                                    // the record reached the flash (only its read-back failed)
        return jump(in, false);
    case BR_RESTORE:
        if (r->offset == 0) {
            if (!vb(in)) {  // checked before QSPI is erased
                if (vq(in)) {
                    set_state(in, BR_CONFIRMED, RSN_BACKUP_BAD);
                    break;
                }
                in->rows |= INSTALL_ROW(9);
                return INSTALL_RESCUE_RETRY;
            }
            memcpy(r->backup, in->hb.raw, IMG_CORE);
        }
        res = run_copy(in, in->spi, SPI_BACKUP, in->qspi, QSPI_SLOT, image_len(r->backup), &in->vq);
        if (res != CONTINUE)
            return res;
        if (vq(in) && !memcmp(in->hq.raw, r->backup, IMG_CORE)) {
            set_state(in, BR_CONFIRMED, RSN_RESTORED);
            r->verify_fail = 0;
        } else {
            r->verify_fail++;
            set_state(in, BR_RESTORE, RSN_NONE);
        }
        break;
    default:
        set_state(in, BR_CONFIRMED, RSN_NONE);  // bootrec_read never returns another state
        break;
    }
    if (!put(in))
        return rec_failed(in);
    return CONTINUE;
}

// ---- the decision table -------------------------------------------------------------------

static void begin(install_t *in)
{
    in->vq = in->vb = in->vs = -1;
    in->degraded = false;
    in->prev_degraded = in->ho->degraded;
    in->ho->degraded = 0;
    handoff_store(in->ho);
}

static install_result_t decide(install_t *in)
{
    for (int guard = 0; guard < 64; guard++) {
        if (!vq(in) && !vb(in) && !vs(in)) {
            in->rows |= INSTALL_ROW(1);
            return INSTALL_RESCUE_HALT;
        }
        bootrec_t *r = &in->rec;
        bool exhausted = r->attempts > 3 || r->verify_fail >= 2;
        if (r->state == BR_BACKUP && r->attempts > 3) {
            in->rows |= INSTALL_ROW(7);
            set_state(in, BR_CONFIRMED, RSN_BACKUP_ABORTED);  // BACKUP only read QSPI: it is intact
            r->verify_fail = 0;
            if (!put(in))
                return rec_failed(in);
            continue;
        }
        if (r->state == BR_WRITE && exhausted && vb(in)) {
            in->rows |= INSTALL_ROW(8);
            enter_restore(in, RSN_WRITE_EXHAUSTED);
            if (!put(in))
                return rec_failed(in);
            continue;
        }
        if ((r->state == BR_WRITE && exhausted) || (r->state == BR_RESTORE && exhausted)) {
            in->rows |= INSTALL_ROW(9);
            return INSTALL_RESCUE_RETRY;
        }
        in->rows |= INSTALL_ROW(10);
        int res = step(in);
        if (res != CONTINUE)
            return (install_result_t)res;
    }
    in->rows |= INSTALL_BUG;
    return INSTALL_RESCUE_HALT;
}

install_result_t install_run(install_t *in)
{
    begin(in);
    int rr = bootrec_read(in->spi, &in->rec);
    if (rr < 0)
        return rec_failed(in);  // the record cannot be read: rows 3-6, never "no record"
    if (rr == BOOTREC_NONE) {
        // First boot after SWD flashing, or both records damaged (spec §11.2).
        memset(&in->rec, 0, sizeof in->rec);
        if (vq(in)) {
            set_state(in, BR_CONFIRMED, RSN_FIRST_BOOT);
        } else if (vb(in)) {
            enter_restore(in, RSN_FIRST_BOOT);
        } else if (vs(in)) {
            in->rows |= INSTALL_ROW(9);
            return INSTALL_RESCUE_RETRY;
        } else {
            in->rows |= INSTALL_ROW(1);
            return INSTALL_RESCUE_HALT;
        }
        if (!put(in))
            return rec_failed(in);
    }
    return decide(in);
}

install_result_t install_rescue_retry(install_t *in)
{
    begin(in);
    in->ho->ram_fail = 0;
    handoff_store(in->ho);
    int rr = bootrec_read(in->spi, &in->rec);
    if (rr < 0)
        return rec_failed(in);
    if (rr == BOOTREC_NONE)
        memset(&in->rec, 0, sizeof in->rec);
    if (vb(in)) {
        enter_restore(in, RSN_RESCUE_RETRY);
    } else if (vs(in)) {
        memcpy(in->rec.staging, in->hs.raw, IMG_CORE);
        set_state(in, BR_WRITE, RSN_RESCUE_RETRY);
        in->rec.verify_fail = 0;
    } else if (vq(in)) {
        set_state(in, BR_CONFIRMED, RSN_RESCUE_RETRY);  // no source to recover from, but QSPI is good
        in->rec.verify_fail = 0;
    } else {
        in->rows |= INSTALL_ROW(1);
        return INSTALL_RESCUE_HALT;
    }
    // A record that cannot be written goes through rows 3-6 like anywhere else: a valid QSPI is
    // run degraded (never erased), rec_fail is counted, and only then the RAM path.
    if (!put(in))
        return rec_failed(in);
    return decide(in);
}
```
